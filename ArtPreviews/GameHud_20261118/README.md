# 전투 HUD 개편

기존 UICanvas.prefab의 GameInfoPanel과 PlayerTurnPanel을 수정했습니다. 메뉴·결과 화면과 이어지는 네이비·금색 구성으로 정리하고, 기존 타워 생성 아이콘을 재사용했습니다. 새 그림 파일은 만들지 않았습니다.

- 상단: 스테이지 이름·WAVE, 적 수/한도, 보유 골드, 플레이어 레벨·EXP 숫자와 진행률.
- LIFE는 이 게임의 적 수/한도입니다. 한도의 80%부터 주황, 한도 도달 시 붉은색으로 표시합니다. 보스가 있으면 웨이브 옆에 남은 턴을 표시합니다.
- 하단 왼쪽: 타워 생성, 실제 생성 비용(현재 250골드).
- 하단 오른쪽: 경험치 투자, 구매 EXP와 실제 골드 비용(현재 100골드당 1 EXP). 기존 색상별 강화 UI는 제거했습니다.
- 플레이어 레벨/EXP는 적 턴에도 상단에 유지합니다. 행동 버튼은 기존 턴 규칙대로 적 턴에 숨깁니다. 골드가 부족하면 비활성화하고 최대 레벨에서는 EXP 구매를 막습니다.
- 레벨업 시 숫자에 작은 DOTween 강조를 주고, EXP 바는 부드럽게 갱신합니다. 현재 공통 ColorUpgradeState와 기존 TryBuyXp를 사용하므로 모든 타워의 강화 레벨도 그대로 연결됩니다. 비용·EXP 요구량·밸런스 수치는 변경하지 않았습니다.
- 젬 그룹·아이콘·옛 젬 비용 표시는 HUD에서 제거했습니다. CurrencyManager는 원래부터 골드만 사용하는 상태였습니다. 관련 그림 원본을 프로젝트에서 일괄 삭제한 것은 아닙니다.
- 설정 버튼과 기존 턴 종료는 유지했습니다. 배속 버튼은 개발용 배속과 같은 ×1 → ×2 → ×3 순환으로 연결하고, 현재 배속을 표시합니다.

하단 버튼은 화면이 좁아지면 크기를 조정합니다. 1920×1080과 1728×1080에서 대기석 칸을 가리지 않는지 확인했습니다. 16:10에서 기존 월드의 시너지 영역 일부가 잘리는 문제는 이번 HUD 변경 범위에 포함하지 않았습니다.

## 적용 파일과 씬

기존 GameInfoPanel.cs·PlayerTurnPanel.cs·UICanvas.prefab을 변경했고, GameHudSetup/GameHudVerification 에디터 도구를 추가했습니다. 공용 프리팹을 사용하는 다른 스테이지에도 표시가 이어집니다.

예전 Stage1의 좌표 오버라이드가 새 배치를 덮어쓰고 있어 변경 대상 HUD 컨트롤의 RectTransform 배치 오버라이드만 Unity API로 해제했습니다. Stage2~10은 같은 항목을 확인했으나 저장할 변경이 없었습니다. 판·대기석·시너지 타일·캐릭터·적 에셋은 수정하지 않았습니다. `scene-placements.txt`에 씬별 내역이 있습니다.

원본 백업은 `ArtBackups/GameHud_20261118`에 있습니다. 기존 코드·프리팹과 스테이지 씬·.meta를 원래 상대 경로로 보관했습니다. 씬 백업은 배치 정리 직전 시점입니다. 이후 수정이 있다면 백업을 덮어쓰지 말고 필요한 변경을 먼저 보관하세요.

## 확인과 미리보기

[초기 1920×1080](hud-initial-1920.png) · [초기 1728×1080](hud-initial-16x10.png) · [레벨 2](hud-level2-1920.png) · [최대 레벨](hud-max-1920.png)

Unity의 실제 Stage1에서 검증용 골드·EXP·기물·적을 사용한 캡처입니다. 에디터 종료 시 테스트 상태는 남기지 않았습니다.

- PlayMode 44항목: 실제 포인터 클릭, 소환과 골드 차감, EXP 구매, 레벨업·모든 컬러 레벨 동기화, EXP 바·골드 갱신, 잔액 부족, 최대 레벨, 설정·배속, 실제 적 턴의 상단 정보 유지와 행동 UI 숨김 등을 검사했습니다.
- 두 화면 비율에서 HUD 텍스트 영역·하단 버튼 화면 내부·대기석 칸 중심 비가림을 검사하고 이미지를 직접 비교했습니다.
- 새 HUD 오류 0건. 기존 TowerFactory의 persistent parent 참조 오류 7건은 별도 기록했습니다.
- 전체 스테이지 자연 클리어·장시간 플레이·배포 빌드는 수행하지 않았습니다.

최종 결과는 `playmode-result.json`과 `verification.json`입니다. 제작 중 진단 기록은 earlier-로 시작하는 파일로 구분했습니다. 중간 DLL 파일 잠금에 따른 컴파일 상태는 Unity의 스크립트 캐시 재컴파일로 해제했고, 그 뒤 최종 PlayMode 검증을 다시 통과했습니다.

Tools > SquareTD > 게임 HUD 적용은 두 HUD 영역을 다시 구성하고 변경 대상의 옛 좌표 오버라이드를 정리합니다. 직접 꾸민 뒤에는 별도로 보관하고 실행하세요. Tools > SquareTD > 게임 HUD 검증은 씬 저장·플레이 종료·밸런스 시뮬레이션 종료 상태에서 실행하며, 확인 후 원래 씬으로 돌아옵니다.
