# 포트폴리오용 사운드 적용

직접 합성한 WAV 113개를 `Assets/4. Asset/6. Audio`에 저장하고 SoundManager에 연결했습니다. 외부 음원·샘플을 가져오지 않았습니다. 전문 녹음이나 최종 믹싱을 거친 음원이 아니며, 집에서 직접 듣고 볼륨과 선호도를 확인하는 단계가 남아 있습니다.

| 분류 | 개수 | 연결 |
|---|---:|---|
| BGM | 3 | 시작·메뉴 / 전투 / 최종 보스 웨이브 |
| UI·게임 이벤트 | 12 | 클릭·확인·복귀·생성·합성·강화·웨이브·승패·존 접촉 등 |
| 기본 공격 | 14 | 문양별 발사 시점 |
| 명중 | 14 | 투사체 도착 콜백 |
| 일반 타워 스킬 | 56 | 14문양 × 광역·단일·버프·디버프 역할 |
| 시너지 | 14 | 시너지 사용 이벤트 |

거부음(Denied)은 카탈로그에 준비되어 있으며 실패 판정마다 개별 연결하지는 않았습니다. 전투음은 기존 ProjectileManager와 SkillEffectTable의 연출 경로에 연결했고, 웨이브·타워 생성·합성·레벨업·승패·UI는 씬 이벤트를 통해 재생합니다. 모든 타워의 모든 상황을 개별 청음한 것은 아닙니다.

## 집에서 확인하기

Unity 메뉴 **Tools > SquareTD > 사운드 설정·미리듣기**를 엽니다.

1. 분류를 선택하고 각 파일의 **듣기**를 눌러 확인합니다. **선택**은 Project 창에서 원본 클립을 선택합니다.
2. 전체·배경음악·전투 효과음·UI 볼륨을 따로 조절할 수 있습니다. 설정은 PlayerPrefs에 저장됩니다.
3. **게임 볼륨을 기본값으로**를 누르면 전체 0.65 / BGM 0.24 / 전투 0.45 / UI 0.40으로 돌아옵니다.
4. 편집 모드의 개별 미리듣기는 Unity의 오디오 미리보기 볼륨을 사용합니다. 실제 게임 볼륨은 플레이 모드에서 확인하세요.

SoundManager는 실행 시 자동 생성되어 씬을 넘어 유지됩니다. 씬에 직접 붙일 필요는 없습니다. 로딩 중에는 이전 BGM을 유지하고 목적지에서 0.8초 동안 전환합니다. 효과음 풀은 12개이고 같은 문양의 연타에 재생 간격 제한을 적용했습니다. 피치 변화는 전투 난수와 별개입니다. 밸런스 시뮬레이션에서는 소리를 재생하지 않습니다.

음원을 교체하려면 `Assets/Resources/Audio/SoundCatalog.asset`의 해당 클립을 바꾸면 됩니다. 배열 순서와 문양·역할 대응은 SoundCatalog 및 PortfolioAudioSetup을 참고하세요.

## 파일과 검증

- 원본 WAV: 44.1kHz / 16bit, BGM 스테레오·효과음 모노. 합계 25,904,600 bytes, **24.70 MiB**. 빌드에서 실제 차지하는 크기나 메모리 사용량과는 다릅니다.
- Unity 임포트: Vorbis 품질 0.75, BGM Streaming, 효과음 DecompressOnLoad. 원본 샘플레이트 유지.
- 파일 검증: 113개 크기·샘플레이트·채널·무음·피크·BGM 시작/끝 경계 검사 통과. `audio-analysis.txt`, `asset-summary.txt`에 기록했습니다.
- Unity PlayMode: **26항목 통과**, 메뉴 BGM 실제 재생·씬 이동·14문양 발사/도착·4역할 스킬·시너지 선택·보스 BGM·연타 제한·음소거·난수 독립 등을 검사했습니다. `playmode-result.json`에 기록했습니다.
- 새 사운드 오류 0건. 기존 TowerFactory의 persistent parent 참조 오류 10건은 별도 기록했습니다. 해당 기존 오류는 수정하지 않았습니다.
- 재검증 중 에디터 백그라운드 대기 문제가 있었고 검증기가 백그라운드에서도 프레임을 진행하도록 수정한 뒤 최종 통과했습니다. 이전 실패 기록은 `earlier-verification-error.txt`입니다.
- **사람의 청음·전체 게임 클리어·배포 빌드는 수행하지 않았습니다.** 실제 Unity 창 캡처는 도구 시간 초과로 확보하지 못했습니다. 위 PlayMode 결과는 Unity API로 측정한 값입니다.

## 변경·백업

기존 변경 파일은 ProjectileManager.cs와 EffectTables.cs 두 개입니다. 작업 전 파일과 .meta는 `ArtBackups/Audio_20261118`의 원래 상대 경로에 보관했습니다. 기존 두 .meta는 유지했습니다. 사운드 매니저·카탈로그·씬 이벤트·UI 클릭 처리·에디터 도구와 오디오 에셋은 새로 추가했습니다. 씬·프리팹은 변경하지 않았습니다.

생성 소스는 `GenerateAudio.cs`, 변경·백업 해시는 `verification.json`에 있습니다. 생성기를 다시 실행하면 WAV를 덮어쓰므로 수작업으로 음원을 바꾼 뒤에는 주의하세요. 새 오디오 폴더와 새 코드까지 제거하려면 기존 두 코드 파일도 함께 백업에서 복원해야 합니다.
