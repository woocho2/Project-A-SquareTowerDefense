## 제작과 정리

내장 image_gen으로 손그림 형태의 원본 3장을 생성했다. 생성 원본은 각각 1254×1254이며, 네이티브 2048 생성으로 표기하지 않는다.
프레임별 크롭, 중심 정렬, 궤적 앞끝의 각도·반지름 정규화, 최종 규격으로 리샘플링, 중립 회색조 변환, 저알파 배경·고립 잡티 제거를 거쳤다.
초반의 짧은 궤적을 원으로 잘못 피팅해 커지는 문제를 수정했고, 흩어지는 마지막 4프레임은 명도와 불투명도가 내려가도록 정리했다.
투명 경계에 붙어 있는 안티앨리어싱은 보존했다.

## 파일상 확인

- 세 파일 모두 요구 크기 및 16프레임.
- 모든 셀의 사방 16px 영역에서 알파가 0보다 큰 픽셀: 0.
- 알파가 있는 픽셀에서 R/G/B 불일치: 0.
- 알파가 있는 픽셀에서 회색값 90 미만: 0.
- 알파 1~20 픽셀 중 4px 이내에 알파 21 이상의 획이 없는 고립 잡티: 0.
- 회전 궤적 프레임 0~11의 밝은 앞끝: 반지름 약 204.7~206.4px, 3시에서 약 0.1~1.8도 범위.
- 궤적 머리를 3시에 유지하고 꼬리가 시계 방향으로 이어지는 프레임 구성을 확인했다.
- 각 GIF를 다시 열어 512×512, 16프레임으로 해독되는 것을 확인했다.
- GIF는 10ms 단위 형식이므로 미리보기 한 주기는 궤적 약 0.80초, 타격 약 0.32초, 충격파 약 0.48초다. 실제 게임의 셰이더 프레임 보간과 재생 타이밍은 기존 코드가 담당한다.

상세 픽셀 결과는 Flipbook_Pixel_QA_*.csv에 기록한다.

## 임포트

Texture Type Default / Alpha Is Transparency / Clamp / Bilinear / Compression None / Mipmap Off / Max Size는 파일 크기 이상.
교체 파일이 있으면 PNG와 .meta를 ArtBackups에 보관하고 기존 GUID를 유지한다.

## 범위와 한계

기존 도끼 원화, C# 게임 코드, FlipbookFx.shader를 수정하지 않았다. 기존 Resources 이름에 맞춰 PNG와 임포트 메타데이터만 추가·교체했다.
Unity 컴파일, Play, 게임 화면 렌더 검증은 수행하지 않았다.
시트와 프레임 미리보기 및 파일 규격을 확인한 결과이며, 출시 품질이나 게임 내 타격 피드백을 검증했다는 뜻이 아니다.
