# 승리·패배 결과 패널

Stage1의 GameClearPanel과 GameOverPanel을 공통 결과 화면으로 연결했습니다. 기존 UICanvas.prefab 안의 두 패널 루트와 스크립트 GUID는 유지하고, 내부 UI만 Unity 프리팹 API로 구성했습니다. 같은 프리팹을 사용하는 다른 스테이지에도 적용됩니다. 씬 파일은 직접 수정하거나 저장하지 않았습니다.

- 승리: **스테이지 클리어** / 다음 스테이지 / 스테이지 선택
- 패배: **도전 종료** / 다시하기 / 스테이지 선택
- 얼굴·이름·역할·배치·티어·실제 누적 피해·피해 비중을 기물마다 한 줄씩 표시합니다. 피해량 내림차순이며, 같은 캐릭터 여러 기를 하나로 합치지 않습니다.
- 전장·대기석·시너지 칸에 종료 순간 보유한 기물을 모두 포함합니다. 목록은 스크롤할 수 있습니다. 이미 팔거나 파괴한 기물은 표시하지 않습니다.
- 누적 피해는 방어·저항 등 기존 피해 계산을 거쳐 실제로 깎은 체력입니다. 남은 체력을 초과한 피해는 제외하고, 기본 공격·스킬·지속 피해·처형을 포함합니다. 공격자 정보가 있는 피해만 해당 기물에게 귀속합니다. 버프·디버프의 간접 기여는 피해량으로 환산하지 않습니다.
- 합성된 기물은 재료 기물의 피해 기록을 이어받습니다. 이전 기물의 공격자 참조로 들어오는 늦은 지속 피해도 합성된 기물에게 귀속합니다.
- GameSession의 실제 승리·패배 처리에서 스냅샷을 만들므로 이후 피해·합성·기물 변경이 결과를 바꾸지 않습니다. 편집 중 클리어 패널을 켜 두어도 게임 시작 시 결과를 미리 확정하지 않습니다.

다시하기와 다음 스테이지는 덱·난이도를 유지하고, 기물·피해 기록은 새 판으로 초기화합니다. 다음 스테이지는 StageDefinition의 번호와 실제 씬을 함께 변경합니다. 다음 씬이 없으면 다음 버튼을 비활성화합니다. 모든 이동은 공용 LoadingScene을 경유하며 중복 입력을 막습니다.

## 검증

- Unity PlayMode 동작 **27항목 통과**. 실제 EnemyController.TakeDamage/Execute, 실제 자동 합성, 승패 이벤트와 UI 표시, 재시작, Stage2 진입, 메뉴 복귀를 사용했습니다.
- 텍스트 영역 204개 검사 통과. 전체 보고서의 검사 항목 수는 231개입니다.
- [패배 1920×1080](defeat-1920.png), [패배 1728×1080](defeat-16x10.png), [승리 1920×1080](victory-1920.png)를 Unity 카메라로 렌더링하여 직접 확인했습니다. 검증용 피해 수치와 기물입니다. 화면 원본에는 보유 기물이 더 있어 아래로 스크롤할 수 있습니다.
- 새 결과 패널 오류 0건. 기존 TowerFactory의 persistent parent 참조 오류 19건은 playmode-result.json의 existingErrors에 별도 기록했습니다. 기존 메뉴 Missing Script 경고도 남아 있습니다.
- 마지막으로 밸런스 시뮬레이션 중 결과 UI 기록 생성을 건너뛰는 조건을 추가하고 컴파일했습니다. 실제 UI 검증은 일반 플레이 모드 기준입니다. 배포 빌드·전체 스테이지 자연 클리어·장시간 플레이는 수행하지 않았습니다.

Tools > SquareTD > 승패 결과 패널 검증에서 저장된 씬으로 실제 전환 검증을 다시 실행할 수 있습니다. 종료 후 원래 열린 씬으로 돌아옵니다. 진행 중인 시뮬레이션이나 저장하지 않은 씬이 있으면 실행하지 않습니다.

## 변경과 백업

주요 새 코드: BattleResults(기록·스냅샷), BattleResultPanel(공용 화면·이동), BattleResultRow(기물 한 줄).
기존 EnemyController의 피해 적용 지점, GameSession의 종료 지점, TowerManager의 합성 지점에 기록 호출을 추가했습니다. 피해 계산식·티어·가격·밸런스 수치는 변경하지 않았습니다. 승패 패널 두 개와 UIManager의 결과 표시도 연결했습니다.

작업 전 기존 코드·UICanvas.prefab과 .meta는 `ArtBackups/ResultPanels_20261118`에 원래 경로로 보관했습니다. Stage1 씬 백업은 사용자가 저장하기 전 디스크 내용을 보관한 참고본이며, 이번 작업은 그 뒤 사용자가 저장한 씬을 되돌리지 않았습니다. 원복할 때 Stage1을 이 참고본으로 덮어쓰지 마세요. `verification.json`에 변경 파일·백업 해시와 메타 유지 결과를 기록했습니다.

Tools > SquareTD > 승패 결과 패널 적용은 공용 프리팹의 두 결과 패널 내부를 다시 만듭니다. 직접 UI를 배치한 뒤에는 재적용 전에 별도로 보관하세요. 제작 중 해결한 오류 기록은 earlier-로 시작하는 파일로 분리했습니다.
