Codex 에셋파일 생성 기준 규칙
프로젝트: Project-A-SquareTowerDefense

1. 적용 범위

이 문서는 타워 캐릭터 이미지와 아틀라스를 생성·수정할 때 사용하는 기준이다.
사용자가 이후에 명시한 수정 사항은 이 문서보다 우선하며, 확정된 변경은 문서에도 반영한다.
아직 선택되지 않은 시안이나 제안 사항을 확정된 디자인으로 취급하지 않는다.

2. 무기군: 한 캐릭터의 네 가지 전직

적용 대상: 검, 도끼, 활, 창, 방패, 해머.
무기 문양마다 기본 캐릭터 한 명을 정한다.
같은 무기군의 광역·타겟·버프·디버프는 그 기본 캐릭터가 네 방향으로 전직한 모습이다.
각 전직을 서로 다른 인물로 그리지 않는다.
서로 다른 무기 문양까지 같은 인물로 만들 필요는 없다.

같은 무기군의 네 전직에서 유지할 요소:
- 얼굴형, 이목구비의 모양과 위치, 나이, 표정, 체형.
- 기본 머리스타일, 가르마, 앞머리, 머리선, 묶음머리의 구조.
- 얼굴 크기, 눈높이, 턱 위치, 얼굴과 상체의 비율.
- 몸의 방향, 어깨 높이, 상반신 구도.

전직에 따라 변경할 요소:
- 규칙에 따른 머리색과 눈색.
- 직업별 의상, 무기, 장식과 디자인 중심색.
- 수염이 있는 캐릭터는 수염도 머리색 규칙에 맞춘다. 수염의 기본 형태는 유지한다.

3. 무기군 색상 규칙

역할       머리색             눈색       디자인 중심색
광역       갈색               빨강       빨강
타겟       짙은 남색          파랑       파랑
버프       검정               노랑       노랑·금색
디버프     흰색               보라       보라

전체적인 의상·장식의 중심색은 눈색을 따른다.
피부, 금속, 가죽, 흰 천 등의 소재색은 자연스럽게 함께 사용할 수 있다.
타겟의 머리색은 짙은 남색이며, 버프의 검은 머리와 구분되게 한다.
버프의 머리를 흰색이나 금발로 임의 변경하지 않는다.

4. 원소군: 개별 캐릭터와 괴수

적용 대상: 불, 물, 대지, 바람, 얼음, 전기, 빛, 어둠.
원소군에는 동일 인물의 전직 개념을 적용하지 않는다.
피닉스, 라이트닝 울프처럼 각 콘셉트에 맞는 독립된 캐릭터나 괴수로 제작한다.
같은 얼굴, 사람의 체형, 사람의 머리색·눈색 규칙을 원소군에 강제하지 않는다.
종, 신체 구조, 실루엣, 고유 색상은 각 콘셉트를 따른다.
게임 전체의 그림체, 채색과 아틀라스 규격은 공통으로 맞춘다.

5. 공통 그림체와 구도

현재 확정된 검 타워의 그림체를 공통 스타일 기준으로 사용한다.
정면 상반신 구도, 정면 시선, 세밀한 윤곽선과 채색·명암을 일관되게 유지한다.
상체를 임의로 기울이거나 시점을 바꾸지 않는다.
얼굴이 중심에서 벗어나지 않도록 하고, 밑단은 같은 기준 높이에서 수평으로 자른다.
모자, 머리카락, 수염, 장식이 커졌다는 이유로 얼굴 전체를 축소하지 않는다.
장식과 무기가 얼굴을 가리지 않도록 한다.
승인된 얼굴·머리스타일은 해당 캐릭터의 기준이다. 새 앞머리나 잔가닥을 임의로 추가하지 않는다.

6. 얼굴 크기와 비율 검수

"같은 얼굴 크기"를 프롬프트에 적는 것만으로 크기가 고정되었다고 판단하지 않는다.
완성본을 실제 기준 원본과 겹쳐 보고 눈, 코, 입, 턱, 양쪽 얼굴 윤곽의 위치와 크기를 확인한다.
비교본은 같은 캔버스, 같은 배율과 같은 배치 좌표로 만든다.
전직별로 머리나 모자 외곽에 맞춰 개별 확대·축소하지 않는다.
가로·세로를 따로 늘이거나 줄여 얼굴을 비틀지 않는다.
색상 차이와 얼굴 형태의 변화를 구분해서 검수한다.
얼굴 크기·이목구비가 달라졌으면 수정 후 다시 비교한다.
검수하지 않은 결과를 "얼굴 크기 고정 완료"라고 설명하지 않는다.
아직 기본 캐릭터가 선택되지 않은 탐색 시안과, 동일 인물로 제작하는 전직 시안을 구분한다.
원소 괴수는 사람 얼굴 기준점 대신 해당 캐릭터의 중심, 실루엣, 셀 내 크기와 잘림을 확인한다.

7. 이미지와 아틀라스 규격

캐릭터 한 칸: 512 x 512 픽셀.
아틀라스: 1024 x 1024 픽셀, 2 x 2 배치.
실제 에셋은 알파 채널이 있는 투명 배경으로 만든다.
사방 최소 16px의 투명 여백을 확보해 인접 스프라이트와 섞이지 않게 한다.
캐릭터, 머리, 장식과 무기가 셀 경계에서 잘리지 않도록 확인한다.
실제 에셋에는 이름표, 설명 문구, 테두리, 배경, 바닥 그림자를 넣지 않는다.
미리보기의 배경·이름표는 실제 에셋과 별도로 만든다.

배치 순서:
왼쪽 위: 광역
오른쪽 위: 타겟
왼쪽 아래: 버프
오른쪽 아래: 디버프

파일명은 사용자가 지정한 이름을 우선한다.
현재 확정된 검 아틀라스 이름은 Sword_Atlas.png다.
다른 무기군 아틀라스 이름은 사용자의 지시에 따라 정한다.

8. 제작과 승인 순서

기본 캐릭터 시안 제작 → 사용자 선택 → 기본 원본 확정·보관
→ 같은 인물의 네 전직 제작 → 공통 좌표로 비교·검수
→ 사용자 디자인 확인 → 아틀라스 저장·게임 연결.

사용자가 이미 승인하고 저장·적용을 지시한 단계는 다시 허락을 묻지 않고 진행한다.
새 시안을 만들었다는 이유만으로 승인되지 않은 이미지를 게임 아틀라스에 덮어쓰지 않는다.
수정 요청은 지정된 부분에 적용하며, 승인된 나머지 디자인은 유지한다.
반영 전 원본 이미지와 .meta 파일을 백업한다.
기존 에셋을 교체하거나 이름을 바꿀 때는 .meta를 함께 유지한다.
GUID, 스프라이트 ID, 잘라내기 영역과 카탈로그·프리팹 참조가 유지되는지 확인한다.
파일상 연결 확인과 Unity 실제 플레이 확인을 구분해서 보고한다.

9. 티어 표현

티어별 외형은 기존 타워 외형으로 구분한다.
캐릭터 이미지를 티어마다 새로 그리지 않는다.

11. 현재 도끼 기본 캐릭터 요청

도끼 기본 캐릭터는 중년 남성이며, 수염이 덥수룩한 인상으로 제작한다.
검 타워의 그림체와 공통 비율 기준을 참고한다.
기본 인상은 B · 거친 용병형을 선택했다.
초기 B는 얼굴이 검 타워보다 길어져 있었으므로 전직 제작 기준으로 그대로 사용하지 않는다.
검 타워 기준으로 눈 크기·눈 아래 얼굴·얼굴과 상체 비율을 다시 맞춘 시안은
outputs/axe-base-mercenary-v2/Axe_Base_B_Proportion_Corrected.png에 있다.
동일 배율 비교본은 같은 폴더의 Sword_Axe_Proportion_Comparison.png다.
이후 사용자가 네 전직 제작을 요청하며 직접 첨부한 이미지를 최종 도끼 기본 원본으로 선택했다.
확정 원본: outputs/axe-base-approved/Axe_Base_Approved.png
사용자 첨부 이미지가 이전에 생성한 다른 비율 수정본과 다르면 첨부 이미지를 우선한다.
도끼의 네 전직은 광역 바이킹, 타겟 버서커, 버프 스칼드, 디버프 집행관이다.
현재 네 전직 시안과 원본 대조 결과는 outputs/axe-jobs-v1/에 저장했다.
같은 배율로 배치한 뒤 눈·코·입·수염 끝·양볼을 비교했다.
사용자가 네 전직 시안의 아틀라스 저장을 승인했으며 확정 파일명은 Axe_atlas.png다.
적용 경로: Assets/4. Asset/2. Tower/TowerCharacter/Axe_atlas.png
기존 도끼 아틀라스의 .meta, GUID와 스프라이트 ID를 유지해 카탈로그 연결을 보존한다.
반영 전 백업과 적용 검수 기록: outputs/axe-atlas-apply-v1/


12. 검 타워 포즈 변경 시험 적용 — 2026-10-27

사용자가 네 전직의 동일 포즈를 변경하고 새 시안으로 에셋을 교체하도록 승인했다.
검 타워에는 2장과 5장의 정면·몸 방향·어깨 높이 고정 대신 아래 전직별 포즈를 적용한다.
- 광역 검성: 양손으로 대검을 치켜든 자세.
- 타겟 검객: 몸을 틀어 검을 뽑는 발도 자세.
- 버프 검선: 검결을 맺고 보검을 띄우는 자세.
- 디버프 검귀: 몸을 낮추고 검을 역수로 잡으며 한 손을 앞으로 뻗는 자세.
같은 인물의 정체성과 그림체, 역할별 머리색·눈색·중심색은 유지한다.
기존 Reference.json의 정면 얼굴 좌표는 이전 원본 기록으로 보관하며, 방향이 달라진 새 포즈에 그대로 강제하지 않는다.
1024 x 1024 아틀라스의 512 x 512 네 칸과 최소 16px 투명 여백, 기존 메타·GUID·스프라이트 ID는 유지한다.
기존 검 원본과 메타, 교체 이미지·검수 기록은 outputs/sword-pose-atlas-20261027-v1/에 보관한다.
파일·참조 검증과 Unity에서 실제 플레이한 확인은 별도로 기록한다.
이 항목은 검 타워에 대한 변경이며, 다른 무기군의 미승인 시안을 확정한 것으로 취급하지 않는다.

13. 검 타워: 같은 일러스트의 정보 패널용·보드용 슬라이스 분리 — 2026-10-27

사용자 요청에 따라 새 이미지를 그리지 않고 현재 Sword_Atlas.png의 픽셀을 그대로 사용한다.
기존 512 x 512 전체 슬라이스(52010~52013)는 타워 정보 패널의 일러스트로 유지한다.
같은 PNG에 얼굴·상체 중심의 224 x 224 정사각 슬라이스(52014~52017)를 추가해 보드 위 타워에 사용한다.
타워용 영역은 확대 크롭이므로 머리 끝·무기·옷 전체보다 얼굴과 상체의 가독성을 우선한다.
TowerCharacterCatalog의 characters는 전체 일러스트, towerCharacters는 선택적인 보드용 슬라이스다.
보드용 슬라이스가 없는 다른 문양은 기존 characters를 그대로 사용한다.
TowerVisual.IllustrationSprite를 정보 카드에 전달하고, CharacterSprite는 실제 타워에 표시한 슬라이스를 가리킨다.
PNG와 기존 네 슬라이스의 GUID·ID·영역은 유지한다.
백업 및 검수 기록: outputs/sword-face-slices-20261027-v1/
