# 도끼 기본 캐릭터 확정

사용자가 네 전직 제작 요청에 직접 첨부한 이미지를 `Axe_Base_Approved.png`로 보관했다. 기본 방향은 덥수룩한 수염의 중년 남성, B · 거친 용병형이다.

사용자 첨부 이미지와 일치하는 생성본은 `exec-4b0b02e0-81cf-47bd-96a5-014ec34b505f.png`이다. 이후 별도로 생성했던 다른 비율 수정본을 임의로 대신 쓰지 않는다. 원본은 그대로 복사했으며 SHA-256은 `Master.sha256`에 기록했다.

네 전직은 바이킹(광역), 버서커(타겟), 스칼드(버프), 집행관(디버프)다. 같은 얼굴·머리·수염 형태·표정·몸의 비율을 유지하고 역할별 머리·수염색, 눈색과 의상을 적용한다.
