# 도끼 기본 캐릭터 탐색 시안

내장 image_gen으로 중년 남성·덥수룩한 수염 기본 캐릭터 시안 세 장을 생성했다. 검 기본 B 이미지는 그림체와 구도의 참고로 사용했다. 전직 시안이 아니라 서로 다른 기본 인물 후보이며, 아직 선택되거나 게임에 적용되지 않았다.

- A.png: 묵직한 족장형, 넓고 풍성한 수염과 묵직한 인상.
- B.png: 거친 용병형, 흐트러진 머리와 야성적인 눈매.
- C.png: 차분한 베테랑형, 뒤로 묶은 머리와 아래쪽을 살짝 묶은 풍성한 수염.

모두 갈색 머리·갈색 수염·빨간 눈을 사용한다. 생성된 원본은 그대로 복사하여 저장했고 전체 프롬프트는 prompts.json, 생성 원본 경로는 sources.json에 기록했다.

Axe_Base_Comparison.png는 비교용으로 눈의 중간 높이와 눈 사이 거리를 맞춘 배치다. 붉은 홍채 영역의 색상 중심으로 위치를 측정했으며, 측정값은 Eye_Landmarks.json에 있다. 가로·세로에 같은 배율과 평행 이동만 적용했고 얼굴을 비틀거나 다시 그리지 않았다. 배치 수치는 Comparison_Layout.json에 기록했다. 이 정렬은 탐색 후보의 비교를 돕는 용도이며, 서로 다른 인물의 얼굴형이 동일하다는 뜻은 아니다.

사용자는 B · 거친 용병의 인상을 선택했고 검 타워와 얼굴 비율을 맞추도록 요청했다. 이 폴더의 B는 얼굴이 길게 남아 있는 초기 시안이므로 전직 제작 기준으로 확정하지 않는다. 비율 수정본은 `../axe-base-mercenary-v2/`에 저장했다. 수정본 확인 후 해당 인물의 얼굴과 머리·수염 형태를 도끼군의 4전직 기준으로 고정한다.
