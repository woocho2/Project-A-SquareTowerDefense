# 적 에셋 폴더 통합

사용자가 삭제와 한 폴더 통합을 요청하여 옛 합성 이미지 8개와 메타를 삭제했다. 삭제 직전 Assets 전체에서 해당 GUID 참조가 없음을 다시 확인했다.

현재 사용하는 적 에셋 32개는 `Assets/4. Asset/4. Enemy/` 바로 아래에 모았다. 하위 폴더는 없다.

- 공용 배경·테두리·상태 배지 아틀라스 및 캐릭터·마스크 PNG 9개
- 발키리·브륀힐드·로키 외형 설정 3개
- 상태별 머티리얼 18개와 공용 그림자 머티리얼 1개
- 공용 큐브 메시 1개

이동 전후 모든 파일의 SHA256과 메타 GUID를 검사했다. 현재 프리팹·외형 설정·머티리얼은 GUID로 연결되므로 파일 경로만 옮겼으며, 연결 내용은 바꾸지 않았다. 열린 에디터의 자동 임포트에 대비해 원본 메타를 최종 경로에 복원했다. 빈 Asgard, CubeLayers 등 옛 하위 폴더와 폴더 메타도 정리했다.

`before.zip`에 정리 직전 적 에셋 폴더 전체를 보관하고 압축 항목마다 SHA256을 확인했다. `move-manifest.json`은 이동 경로·GUID·원본 메타·해시 목록, `deleted-images.txt`는 삭제한 8개 이미지 목록이다. 현재 레이어 제작/연결/검사 스크립트와 manifest, 22번 구현 내역서는 새 경로에 맞췄다. 과거 작업의 출력 기록은 그대로 보관한다.

Unity는 실행하지 않았다. 최종 경로·연결 검사는 `outputs/enemy-cube-layers/Verify-Layers.ps1`과 이 폴더의 `verification.txt`에 기록했다.
