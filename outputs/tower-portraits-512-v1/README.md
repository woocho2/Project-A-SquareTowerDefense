# 타워 캐릭터 512px 적용

일반 타워 56종과 시너지 타워 14종, 총 70종을 **한 칸 512×512**로 변경했습니다. 실제 적용 경로는 `Assets/4. Asset/2. Tower/TowerCharacter/`입니다.

- 일반 14개 아틀라스: 512×512 → **1024×1024**, 2×2 배열 유지.
- 시너지 아틀라스: 1024×1024 → **2048×2048**, 4×4 배열과 빈 두 칸 유지.
- 각 스프라이트의 분할 좌표와 크기를 두 배로 변경하고 PPU를 192 → **384**로 맞췄습니다. 월드 캔버스 크기는 기존과 같은 1.3333입니다.
- GUID, spriteID, fileID, 이름, 피벗, 카탈로그·프리팹 연결을 유지했습니다. 무압축, Bilinear, 밉맵 없음과 기존 플랫폼 설정도 유지합니다.

256px 결과를 확대하지 않고 보관된 큰 생성 원본에서 다시 샘플링했습니다. 검객·불도마뱀·빙하·예티는 이후 승인된 수정 원본을 사용합니다. 기존 256px 패킹과 공통 눈·턱·몸 기준을 역변환하여 동일한 배치로 내보냈습니다. 새 원화를 생성하지 않았습니다.

## 확인

전체 70종을 시각 검토했고 투명 여백, 가장자리 잘림 없음, 몸 아래선, 카탈로그 70개 연결을 확인했습니다. 별도 Unity 6000.3.9f1 프로젝트에서 실제 512px 스프라이트를 임포트하고 일반 14문양×4직군×5티어 및 시너지 14종, **294조합**을 GPU 렌더링하여 기존 표시 크기와 연결을 확인했습니다. 전체 스테이지 전투 플레이 검사는 수행하지 않았습니다.

- [전체 70종](all70-overview.png)
- [수정 전후 비교 1](comparison-1.png) / [비교 2](comparison-2.png): 왼쪽 256px 확대, 오른쪽 큰 원본에서 내보낸 512px.
- `verification.json`: 최종 파일·임포터·참조 검증.
- `unity-render-verification.json`: 실제 Unity 렌더 결과.
- `rebuild-report.json`: 원본 경로, 등록 변환, 경계, 파일 해시.
- `before/`: 적용 직전 PNG와 메타 백업. `staged/`: 적용본 사본.

`Rebuild.cjs`는 원본 상태와 변경 충돌을 검사하며 스테이징합니다. `--apply`는 최초 적용과 백업을 함께 수행합니다. 이미 적용했거나 이후 원화가 바뀐 상태에서는 기존 결과를 덮어쓰지 않고 중단합니다. `Preview.cjs`는 미리보기를, `Verify.cjs`는 최종 검증을 재생성합니다. `Prepare-Unity.cjs`와 `Tower512Audit.cs`는 별도 Unity 검증용입니다.
