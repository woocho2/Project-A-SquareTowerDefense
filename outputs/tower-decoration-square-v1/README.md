# 타워 스폰 타일용 장식 보정

`Tile_Path_Overlay_*_Atlas.png` 10개 테마 아틀라스에서 스폰 타일에 쓰는 빈 테두리 `*_FRAME` 조각만 보정했다.

- 실제 그림 영역: 기존 x=6, y=5, 244×242 → x=7, y=7, 242×242
- 256×256 캔버스 중앙에 정렬
- 타일·타워 프레임과 같은 반지름 28px 외곽
- 10종 공통 알파 마스크: 좌우·상하·90도 회전 대칭
- 각 테마 색상과 명암은 기존 픽셀을 좌표 변환하여 보존
- 장식 중앙은 계속 투명

이미지 재생성 없이 System.Drawing으로 좌표와 알파를 보정했다. `Correct-Decorations.ps1`은 `before/` 원본 백업에서 결과를 재현한다. 검토용 파일은 `preview.png`, 픽셀 검증 결과는 `verification.txt`에 있다.

기존 아틀라스의 FRAME 외 11개 조각은 RGBA 값이 그대로 유지된다. 슬라이스 좌표·ID·GUID·피벗·PPU·타일 변환은 변경하지 않았다. 장식 PPU 256 × 기존 타일 배율 1.3333334의 표시 캔버스는 스폰 바닥 PPU 192의 256px 캔버스와 일치한다.

앞서 보정한 캐릭터용 티어·시너지 프레임 6종도 외곽 242×242다. 타워 얼굴·투구 이미지는 이번 장식 보정에서 변경하지 않았다. 일반 타워의 기존 95% 표시 배율과 게임 코드는 유지했다. Unity는 실행하지 않았다.
