# 정사각형 타워 프레임 보정

기존 프레임 색상과 장식을 좌표 변환으로 보존하고, 외곽·안쪽 투명 영역을 공통 정사각형 마스크로 교정했다. 이미지 재생성 없이 System.Drawing으로 픽셀 좌표와 알파를 보정했다.

- 대상: Bronze, Silver, Gold, Mithril, Diamond, Synergy 6종
- 아틀라스: 기존 768×512, 3×2 배치 유지
- 각 셀: 256×256, 기존 PPU 192·중앙 피벗·GUID·스프라이트 ID 유지
- 외곽: PNG 좌표 (7, 7)부터 242×242, 모서리 반지름 28px
- 안쪽: PNG 좌표 (36, 36)부터 184×184, 모서리 반지름 20px
- 테두리 직선부 두께: 상하좌우 29px
- 중심: 모두 픽셀 경계 좌표 (128, 128)
- 배경 프레임 안쪽: 불투명 흰색
- 전경 테두리 안쪽: 투명

`Correct-Frames.ps1`은 `before/` 백업으로부터 보정 PNG와 마스크·미리보기를 재현한다. 보정본은 기존 Assets의 `Tower_Frames_Atlas_v1.png`와 `Tower_Frame_Rims_Atlas_v1.png`에 적용했다. `.meta`는 변경하지 않았다.

`verification.txt`에 여섯 스프라이트의 실제 픽셀 경계, 알파 마스크 일치, 수평·수직·90도 회전 대칭, 흰색 내부 검증 결과를 기록했다. Unity 실행 및 검증은 하지 않았다.

`comparison.png`: 보정 전/후. `spawn-overlay.png`: 실제 스폰 타일과 새 프레임을 같은 256×256 캔버스로 겹친 참고 이미지.

현재 스폰 타일 원본의 보이는 영역은 244×242로 여전히 비정사각형이며, 새 프레임의 242×242와 외곽이 완전히 같지는 않다. 스폰 타일 이미지와 런타임의 기존 95% 표시 크기는 이번 프레임 보정에서 변경하지 않았다. 이후 캐릭터 제작의 공통 안쪽 기준은 `face-opening-mask256.png`의 184×184다.
