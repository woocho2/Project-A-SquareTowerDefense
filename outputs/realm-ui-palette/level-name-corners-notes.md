# TowerInfoPanel Level / Name 모서리 맞춤

두 UI는 실제 높이가 모두 50입니다. Level은 75×50으로 384×256 조각을 표시하고, Name은 300×50으로 768×128 조각을 표시합니다. 기존 아틀라스의 모서리/선/패딩 픽셀 크기는 두 조각에서 같아, Level 쪽은 화면에서 절반 크기로 보였습니다.

A/B/C/Frame의 SkillCard_384x256 네 조각을 해당 레이어의 MegaDock_768x128 기준으로 맞췄습니다. 양쪽 끝 모서리는 유지하고 직선 가운데만 192×128 비율로 줄인 뒤 384×256에 맞춥니다. 따라서 같은 화면 높이로 표시할 때 모서리, 선 두께, 내부 여백의 배율이 같아집니다. 나머지 56개 조각과 아틀라스 빈 공간은 픽셀 단위로 유지했습니다. 텍스처 크기, 스프라이트 개수, 메타데이터, UI 크기 및 연결은 변경하지 않았습니다.

Match-SkillCardCorners.ps1: 재현 가능한 수정 스크립트.
level-name-corners-preview.png: 실제 75×50 / 300×50 UI 배율을 4배로 보여주는 전후 비교.
level-name-corners-validation.txt: 네 레이어의 코너 경계가 같은 UI 높이에서 0.25px 이내로 일치하고 나머지 픽셀이 동일한지 확인한 기록.
