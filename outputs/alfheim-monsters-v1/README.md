# 알프헤임 몬스터 3종 — 2026-10-17

최종 크기 보정: 전체 외곽 높이 대신 일반 타워의 얼굴 기준으로 다시 배치했습니다. 최신 기준·백업·검사는 `../character-scale-alignment-v1/`에 있습니다. 눈높이 Y160, 눈 간격 약 39.5px, 턱 Y184, 몸 아래선 Y244(256 논리 셀 기준)이며, 관·귀·머리카락 때문에 전체 외곽 크기는 달라도 얼굴 기준은 같습니다. 아래 최초의 400×378 외곽 규격은 제작 초안의 설명입니다.

`Assets/20. 통합 기획서.txt` 9장 [스테이지의 적과 해금]을 기준으로 2스테이지의 일반 적·중간 보스·최종 보스 외형을 제작했습니다. 프레이를 타락한 보스로 만들지 않고 엘프의 상위 계급으로 구분했습니다. 내장 image_gen을 사용했으며 전체 프롬프트는 `prompts.json`에 있습니다.

|---|---|---|---|
| 일반 적 | 타락한 엘프 | `CorruptedElf` | 밝은 애쉬 금발, 보라색 눈, 작은 잎 머리핀 |

사용자 후속 요청에 따라 부족장과 족장의 머리·눈 색을 각각 다르게 했습니다. 피부와 보랏빛 타락 문양, 은색 장비와 보석 디자인을 유지했으며, 장비 상태 색으로 머리·눈까지 바뀌지 않게 마스크에서 보호했습니다. 세 캐릭터는 정면 한 장을 큐브의 상태별 면에서 공용으로 쓰는 기존 구조를 따릅니다.

## 저장 위치와 구성

`Assets/4. Asset/4. Enemy/Alfheim/`

각 접두사에 다음 세 파일과 Unity `.meta`를 저장했습니다.

- `_Character.png`: 512×512 RGBA 투명 캐릭터 텍스처. 기존 타워 기준으로 가로 최대 400px, 높이 378px, 아래 기준선 496px에 맞췄습니다. 머리·장식 모양을 찌그러뜨리지 않도록 비율을 유지합니다.
- `_EquipmentMask.png`: 512×512 불투명 RGB 흑백 장비 마스크. 흰색만 장비 상태 색으로 바뀝니다. 피부·목·눈·머리카락은 제외합니다. 선형 데이터(sRGB 해제), 무압축, 밉맵 없음입니다.
- `_Appearance.asset`: 기존 `EnemyCubeAppearance` 형식으로 해당 캐릭터·장비 마스크를 참조합니다. `EnemyCubeMeshVisual.SetAppearance` 또는 Inspector의 Appearance에 사용할 수 있습니다.

스테이지2의 웨이브·풀·프리팹·씬 소환 연결이나 적의 스탯/능력 구현은 이번 에셋 제작에 포함하지 않았습니다. 기존 게임 에셋과 코드는 수정하지 않았습니다. 공용 배경·장식·상태 배지·기본 6색 팔레트를 그대로 재사용할 수 있습니다. 별도의 6색 중복 PNG나 상태별 신규 재질은 추가하지 않았습니다.

## 확인 자료

- `overview.png`: 일반 / 부족장 / 족장 최종 비교.
- `six-state-preview.png`: 위에서 일반 / 부족장 / 족장, 왼쪽부터 회복 / 방어 / 행동 / 이동 / 자물쇠 / 모래시계. 현재 공용 텍스처와 팔레트를 CPU로 합성한 미리보기이며 Unity 렌더링은 아닙니다.
- `equipment-mask-check.png`: 장비 선택 영역을 빨간색으로 강조한 점검 그림.
- `asset-manifest.json`: GUID와 배치 범위.
- `verification.json`, `mask-verification.json`: 텍스처 크기·알파·마스크 흑백/경계·선형 임포트·외형 설정 참조 확인. Unity 임포트·플레이 검증은 수행하지 않았습니다.
- `source/`: 이미지 생성 원본과 이전 시안. 게임에서 직접 참조하지 않습니다.

최종 재패킹은 `node outputs/alfheim-monsters-v1/Rebuild-Final.cjs`를 사용합니다. 원본 패킹 → 마스크 제작 → 공통 얼굴 크기 보정 → 미리보기 순서이며, 외곽 기준 패킹만 다시 적용해 크기 보정이 사라지는 것을 막습니다. 새 그림을 제작해 원본이 달라졌다면 공통 크기 보정의 얼굴 랜드마크를 먼저 갱신해야 합니다. 이미지 생성 원본은 보관합니다. 부족장 마스크의 위치 보정과 피부 보호, 장비 내부의 작은 빈 구멍 보정은 마스크 제작 코드에 기록했습니다.
