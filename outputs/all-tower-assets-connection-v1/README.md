# 전체 타워 에셋 연결

일반 캐릭터 56종(5티어로 280개 조합)과 시너지 캐릭터 14종을 실제 타워 표시 경로에 연결했습니다. 검·도끼의 얼굴/장식 레이어를 유지하며, 나머지 48종은 `TowerCharacterCatalog.asset`의 완성 초상을 공용 티어 프레임 위에 표시합니다. 소환·티어 강화·외형 교체가 같은 `TowerVisual.Apply` 경로를 사용합니다. 일반 타워 캔버스는 기존과 같은 1.2666667 월드 단위, 시너지는 256px/192PPU입니다.

## 데이터와 번호

현재 런타임 문양 번호는 확정 기획과 같습니다.

`01 검, 02 도끼, 03 활, 04 창, 05 방패, 06 해머, 07 불, 08 물, 09 대지, 10 바람, 11 얼음, 12 전기, 13 빛, 14 어둠`

`Assets/Resources/TowerDataCSV.csv`에 물의 4역할×5티어 20행을 추가하여 280행이 되었습니다. 기존 260행은 이름과 모든 기본 수치를 보존하고 ID·이펙트 번호만 변환했습니다. 물의 기본 수치는 미정이므로 **같은 티어·역할의 바람 타워 수치를 임시로 복사**했습니다. 예: 1108 파도술사, 1208 운디네, 1308 나이아드, 1408 세이렌.

**물 전용 스킬(쓰나미·물대포·물결/해류·젖음/침수)은 이번 작업에서 구현하지 않았습니다.** 이번 범위는 소환 데이터, 기본 공격의 투사체/이펙트, 역할별 초상과 문양, 시너지 생성 조건입니다. 버프/디버프 데이터와 존의 물 종류는 등록되어 있으며 전용 전투 효과는 후속 구현이 필요합니다. 시너지의 공격/버프 능력도 기존처럼 생성·표시 전용입니다.

게임이 읽는 파일은 CSV입니다. `TowerDataCSV_master.xlsx`와 `TowerBalance.xlsx`는 이번 변경 대상이 아니므로 이전 번호/행 수가 남아 있습니다. 워크북에서 다시 CSV를 내보내기 전에 새 번호와 물 20행을 반영해야 합니다. 이전 CSV 원본은 `before/TowerDataCSV.csv`, ID 변환표는 `emblem-migration.json`에 보관했습니다.

## 시너지

기존 6001~6013의 인물 ID를 유지하고 뇨르드를 6014에 추가했습니다. 카탈로그의 14개 정면을 모두 v3로 변경했습니다.

- 발드르(6007): 물 · 불 · 빛.
- 스카디(6008): 활 · 얼음 · 물.
- 뇨르드(6014): 물 · 바람 · 방패.

세 문양의 4티어 이상 타워가 있으면 기존 생성 로직이 시너지를 만듭니다. 14문양이 각각 세 조합에 사용되며 모든 재료가 실제 CSV에 존재합니다.

## 투사체·이펙트

`Resources/Projectiles/`의 기존 프리팹과 .meta를 충돌 없이 두 단계로 이동하여 새 번호와 맞췄습니다. GUID를 유지해 다른 참조도 보존했습니다. 물의 108/208 프리팹은 전용 그림을 사용합니다. 공용 프리팹의 문양 목록과 디버프 위성 문양도 14종으로 변경했습니다. 얼굴을 투사체에 복사하지 않고 문양/전용 그림을 사용합니다.

이펙트 라이브러리의 번호와 실제 프리팹 GUID/fileID를 맞추고, 기존 활 이펙트의 현재 프리팹→컨트롤러→클립 GUID 연결을 복구했습니다. 원래 삭제된 프리팹을 가리키던 미사용 레거시 버프 항목은 현재의 월드 `MapBuff.prefab`으로 연결했습니다. 원소 이펙트 파일의 기존 이름과 GUID는 유지하고 라이브러리 키를 새 번호로 연결합니다.

물 보조 그림은 내장 `image_gen`으로 제작했습니다. 원본과 정확한 생성/교정 프롬프트는 `water-art/`에 보관했습니다.

- `Assets/4. Asset/2. Tower/Emblem_Water_White.png`
- `Assets/4. Asset/3. Projectile/Cartoon/Bullet/Bullet_Water.png`
- `Assets/4. Asset/3. Projectile/Cartoon/Splash/Splash_Water.png`
- `Assets/2. Prefab/4. Effect/Effect_Water_Hit.prefab`와 `Water_Hit` 애니메이션/컨트롤러.

## 검증

현재 프로젝트 전체 런타임 C# 컴파일을 통과했습니다. 별도 Unity 프로젝트에서 실제 게임 스크립트·프리팹·GUID 의존성을 읽어 검증했습니다.

- 280개 일반 타워 외형을 정수 ID와 실제 TowerData 두 API로 적용. 모든 티어 프레임, 검·도끼 레이어, 완성 초상, 색상·크기·정렬 확인.
- 시너지 14종과 일반 타워 사이 전환 시 머티리얼·마스크·추가 레이어 복원. 그림 누락 시 레거시 외형으로 복원.
- 실제 TowerManager CSV 로더로 280행과 1티어 56개를 로드.
- 물 20개를 실제 TowerBase/TowerController.Init으로 초기화하고 역할별 물 그림 확인.
- 실제 14개 시너지 조건 및 TowerController 초기화, 물 재료의 존재, 각 문양 세 번 사용 확인.
- 공격 투사체 28개와 공격 이펙트 28개의 실제 프리팹 참조 확인.
- 기존 260행의 이름·기본 수치가 전부 보존된 것을 비교 확인.

최종 Unity 종료 코드 0. `unity-validation.log`의 세 PASS 기록을 참고하세요. 전체 스테이지 Play Mode 전투, 물 전용 스킬, GPU 렌더 캡처는 이번 검증에 포함하지 않았습니다. 검증용 프로젝트는 게임의 Assets 밖에 있으며 작업 로그와 테스트 소스만 추적합니다.
