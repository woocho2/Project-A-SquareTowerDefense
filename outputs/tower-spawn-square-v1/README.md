# 타워 스폰 타일 10종 정사각형 보정

`Assets/4. Asset/1. BackGround/Tile_Floor_Atlas.png` 안의 `Tile_TowerSpawn_*` 10개 조각에 적용했다.

원본에서 모든 테마의 불투명 그림 영역은 PNG 로컬 좌표 x=6, y=5, 244×242였다. 공통 기준 x=7, y=7, 242×242로 보정하여 중앙 정렬하고, 기존에 보정한 타워 프레임 외곽 알파 마스크와 픽셀 단위로 일치시켰다. 둥근 모서리 반지름은 28px이고, 수평·수직·90도 회전 대칭인 외곽이다. 기존 색과 명암은 좌표 변환으로 보존했다. 색상 그라데이션 자체는 대칭으로 바꾸지 않았다.

- 아틀라스 크기 2048×768, 각 슬라이스 256×256 유지
- `.meta`, GUID, sprite ID, 슬라이스 좌표, PPU, 피벗 유지
- 타워 스폰 조각 외 917,504픽셀은 원본과 RGBA가 정확히 일치
- 10종 외곽 크기·중심·모서리 알파 마스크가 모두 동일
- 이전 타워 프레임 외곽과 같은 알파 마스크 사용
- 게임 코드와 별도 패스/장식 아틀라스는 변경하지 않음
- Unity는 실행하지 않음

`before/`에 원본 PNG와 메타를 보관했다. `Correct-SpawnTiles.ps1`로 보정 결과를 재현할 수 있다. 이미지 재생성 없이 System.Drawing으로 좌표와 알파를 보정했다.

`comparison.png`: 10개 조각 보정 전/후. `frame-overlay.png`: 같은 캔버스 크기로 보정 타일과 타워 프레임을 겹친 미리보기. `verification.txt`: 픽셀 검증 결과. 개별 타일 PNG는 검토용이며 Assets에 추가하지 않았다.
