# 출발 자리 유지 및 오른쪽 빈자리 탐색

`TileManager.TryGetFreeEnemySlot`의 선택 순서를 수정했습니다. 목적 타일에서도 출발 타일과 같은 상대 자리를 먼저 선택합니다. 같은 목적지에 이미 예약한 자리가 있다면 그 예약을 유지합니다.

```
0 1 2
3 4 5
6 7 8
```

중앙(4)에 있던 적은 다음 타일에서도 중앙(4)을 먼저 찾습니다. 막혀 있으면 오른쪽(5)부터 찾고, 행 끝에서는 다음 행으로 넘어갑니다. 전체 탐색은 `4 → 5 → 6 → 7 → 8 → 0 → 1 → 2 → 3`처럼 자기 자리에서 시작하여 최대 9자리를 한 번씩 확인합니다. 방향은 이동 방향과 무관하게 화면 기준 오른쪽입니다.

실제 적과 도착 예약 모두 막힌 자리로 취급합니다. 전부 찼다면 기존처럼 이동을 멈춥니다. 오른쪽(5)으로 비켜 도착한 적은 다음 타일에서도 현재 자리인 오른쪽(5)을 우선합니다. 기존 예약 중간에 중앙이 비어도 예약 목적지를 바꾸지 않습니다. 새 소환·풀 재사용처럼 출발 자리가 없는 경우 중앙부터 오른쪽 순서로 배정합니다.

검증: 전체 C# 컴파일 성공. Unity 6000.3.9f1 별도 PlayMode에서 9개 출발 위치를 유지하는 역순 예약, 중앙 충돌 시 즉시 오른쪽 우선, 예약된 오른쪽 자리 회피, 행 끝 순환, 빈자리 발생 후 예약 유지, 실제 세 번 굴림의 우회 착지와 다음 칸·코너·역방향에서 자리 유지, 9마리 동시 이동과 정확한 착지, 풀 재사용 시 선호 자리 초기화를 검사합니다. 기존 정원·랜덤 면·굴림·정방향 점프·그림자 회귀 검사도 함께 실행합니다.

검증 코드는 outputs와 별도 Unity 프로젝트에만 위치합니다. 실제 Stage1 장시간 플레이는 별도로 수행하지 않았습니다.
