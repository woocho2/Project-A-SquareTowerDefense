# 물 엠블럼과 아틀라스 알파 정리

`Assets/4. Asset/2. Tower/Tower_Emblem_White_Atlas.png`를 교체했다. 원래 13개 문양의 위치와 스프라이트 이름·ID는 그대로 유지하고, 빈 칸(이미지 좌표 x=256, y=768)에 물방울을 추가했다. 물 스프라이트는 `Emblem_08_Water`, fileID 1014, Unity rect (256,0,256,256), 중앙 피벗, 256 PPU다.

물 그림은 내장 imagegen의 편집 기능으로 파도와 작은 물보라를 없앴다. `prompt.txt`는 사용한 프롬프트, `water-edited.png`는 생성본이다. 가장 큰 물방울 영역만 추출해 높이 180px로 맞추고 256px 셀 가운데에 배치했다.

전체 아틀라스는 알파 128을 기준으로 이진화했다. 1,048,576개 픽셀 모두 `(255,255,255,255)` 또는 `(0,0,0,0)`뿐이다. 중간 알파와 회색은 없다. Unity에서도 가장자리가 보간되지 않도록 Point 필터를 적용했다. 무압축·밉맵 없음은 유지했다.

타워 프리팹과 디버프 프리팹의 물 문양 참조를 새 아틀라스 슬라이스로 옮기고, 기존 `Emblem_Water_White.png`와 메타를 삭제했다. 기존 파일 및 변경 전 프리팹은 `before/`에 보관했다. 실제 Assets에는 물 문양 개별 PNG를 추가하지 않았다.

`preview.png`는 어두운 배경에 표시한 미리보기다. 픽셀 값 검사는 `pixel-verification.txt`에 있다. Unity는 실행하지 않았다.
