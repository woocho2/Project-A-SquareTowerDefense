# 정면 SD 타워 일러스트 v2

2026-10-14. 사용자 제공 직업 소개/초상 선택 이미지의 눈 표현, 얼굴 비율, 선화, 머리카락과 의상 묘사를 참고하여 제작했다. 원본 캐릭터를 복사하지 않고 `Assets/20. 통합 기획서.txt`의 컨셉에 맞춰 새 일러스트로 그렸다.

## 제공 에셋

최종 폴더: `Assets/4. Asset/2. Tower/Portraits_SD_Front_v2/`

- 일반 타워: 문양 14개 × 공격 방식 4개 = 56종. 문양별 512×512 아틀라스 14개.
- 시너지 타워: 14종. 1024×1024 아틀라스 1개.
- 총 70개 캐릭터 스프라이트, 총 15개 PNG 아틀라스.
- 모든 스프라이트 셀은 256×256, PPU 192, 중앙 피벗, Full Rect, Bilinear, 압축 및 밉맵 없음.
- 프레임·배경·독립 문양을 포함하지 않는 투명 캐릭터 일러스트다. 모자·옷·장비에 붙은 작은 장식은 캐릭터 디자인의 일부다.
- 정면 얼굴과 시선을 기준으로 만들었다. 검객은 사용자 요청에 따라 양쪽 눈을 뜬 표정으로 수정했고, 오딘의 안대 등 컨셉 특징은 유지했다.
- 대부분의 일러스트는 로컬 좌표 y56~243, 최대 너비 216px 안에 배치했다. 몸체 아래 기준선은 y244 픽셀 경계로 맞췄다. 모자·뿔·종족 외형 때문에 얼굴과 머리의 실제 경계는 완전히 동일하지 않다. 브록 & 에이트리는 두 인물이 한 셀을 공유한다.

## 연결할 때

일반 아틀라스의 순서는 **왼쪽 위 광역 → 오른쪽 위 단일 → 왼쪽 아래 버프 → 오른쪽 아래 디버프**다. 스프라이트 이름에 문양·컨셉이 들어 있다. 예: `Tower_Sword_Hero_Front_v2`.

시너지는 현재 `SynergyCharacterCatalog`의 ID 순서로 배치했다: 오딘(6001), 토르(6002), 로키(6003), 헬(6004), 수르트(6005), 프레이(6006), 발드르(6007), 스카디(6008), 프레이야(6009), 이미르(6010), 울르(6011), 브륀힐드(6012), 브록 & 에이트리(6013), 뇨르드(6014).

`portrait-map.csv`와 `asset-manifest.json`에 각 스프라이트 이름·ID·아틀라스·슬라이스 좌표를 정리했다. 사용자가 프리팹에 문양과 컬러를 별도로 구성하므로 런타임/카탈로그/프리팹 연결은 수정하지 않았다. 기존 일러스트를 참조하는 부분은 새 스프라이트에 연결해야 새 그림이 표시된다.

프레임 아래에 몸이 자연스럽게 가려지도록, 프리팹에서 프레임을 캐릭터보다 앞 레이어에 놓고 몸의 아랫부분과 아래 프레임 윗선을 맞추면 된다.

## 제작 및 검토

내장 imagegen으로 18개 원본 묶음을 생성했다. 프롬프트는 `prompts/`, 원본은 `source/`에 있다. `Pack-Portraits.ps1`은 인접 캐릭터의 잔여 조각과 아틀라스 경계의 가는 줄을 제거하고 같은 캔버스에 패킹한다. 캐릭터를 새로 그리는 작업은 imagegen으로 수행했으며 패킹은 System.Drawing으로 했다.

- `normal-preview.png`: 일반 타워 56종 전체
- `synergy-preview.png`: 시너지 14종 전체
- `Save-Assets.ps1`: 최종 에셋과 Unity 스프라이트 메타 저장
- `verification.txt`: 최종 픽셀·메타 검증 결과

Unity 실행 및 검증은 사용자가 수행한다. 이 작업에서는 코드 변경, Unity 실행, 프리팹 연결을 수행하지 않았다.

## 검객 표정 수정 (2026-10-14)

`edits/swordsman-open-eyes/`에 내장 imagegen 수정 프롬프트(`prompt.txt`), 원본 및 수정 결과를 보관했다. 새로 생성한 눈 부분만 원본 검객에 합성했으므로 그 영역 밖의 모든 픽셀과 다른 검 타워 3종은 동일하다. 최종 아틀라스 GUID, 스프라이트 이름, 슬라이스 및 배치도 그대로다.

원본 묶음에서 아틀라스를 다시 패킹·저장한 경우, 마지막에 `edits/swordsman-open-eyes/Apply-Edit.ps1`을 실행하여 눈 수정과 미리보기를 다시 적용한다. 최초 제작 프롬프트와 원본은 제작 기록으로 남겨 두었다.

## 글래셔·예티 수정 (2026-10-14)

사용자가 선택한 **작은 눈 + 일자 입의 글래셔**, **작은 동물 눈 + 뿔 없는 예티**를 얼음 아틀라스 아래 두 셀에 반영했다. 글래셔의 입 없는 비교 시안은 적용하지 않았다. 소서러와 잭 프로스트의 픽셀, 아틀라스 크기, 스프라이트 메타는 유지했다.

`edits/ice-creatures-approved/`에 내장 imagegen의 최종 수정 프롬프트(`prompt.txt`), 승인 원본(`native-approved.png`), 수정 전·후 아틀라스와 검증 결과를 보관했다. `Apply-Edit.ps1`은 두 그림을 기존 256×256 셀 크기와 y244 기준선으로 패킹하고 최종 에셋과 전체 미리보기를 갱신한다. 원본 묶음에서 재패킹·저장할 때 마지막에 실행하면 이 수정이 다시 적용된다.
