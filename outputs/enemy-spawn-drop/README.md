# 큐브 적 소환 낙하

풀에서 큐브 적을 꺼내 자리·체력을 초기화한 뒤, 위에서 가속해 떨어지는 연출을 재생합니다. 기본 0.68초 동안 낙하 → 착지 압축 → 작은 반동 → 복원으로 이어집니다. `Enemy.prefab`의 `EnemyCubeMeshVisual`에서 높이와 구간 시간을 바꿀 수 있습니다.

메시만 움직여 루트·경로 점유·충돌체는 배정된 자리에 유지합니다. 선택된 정방향 면과 6면 에셋도 유지됩니다. 바닥 그림자는 공중에서 작고 옅어지고 착지 압축 때 넓어집니다. 동일 프레임에 소환하면 동시에 떨어집니다. 모든 낙하가 끝난 뒤 기존 적과 함께 굴러갑니다.

검증: 전체 런타임 C# 컴파일 및 별도 Unity 6000.3.9f1 PlayMode 실행 통과. 9마리 동기화·공중 정원·얼굴/자리 보존·0.68초 복원·일시정지·이동 대기·착지 후 실제 굴림·중단/비활성화·풀 재소환·EnemyManager의 기존 적 대기를 검사했습니다. `SpawnDropChecks.cs`와 `Prepare-Validation.cjs`는 별도 검증 프로젝트만 사용하며 실제 게임에 테스트 코드를 추가하지 않습니다.

`spawn-drop.gif`, `overview.png`는 Unity에서 직접 렌더링한 60프레임으로 만들었습니다. Stage1 전체 플레이는 별도로 검증하지 않았습니다. 이번 변경은 메시 큐브 소환 연출이며, 기존 스프라이트 보스에는 적용하지 않습니다. 랜덤 경로 소환·웨이브 전체 일괄 소환·새 턴 순서와 소환 전 한도 판정은 기획서의 남은 작업입니다.
