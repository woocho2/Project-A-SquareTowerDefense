# 발키리 정면 6면 · 패스 타일 크기 보정

여섯 면의 얼굴과 장식이 제각각이던 크기를 수정했다. 최종본은 **승인된 정면 원본 한 장**과 **실제 패스 타일 장식의 공통 형상**으로 제작한다. 기존 색상 변형 생성본은 제작 기록으로 보존했으며 현재 최종 PNG의 얼굴·장식 배치를 결정하지 않는다.

## 동일한 크기 기준

- 실제 패스 타일 캔버스: **256×256, 192 PPU**, 한 변 **1.3333333 유닛**.
- 몬스터 면 캔버스: **512×512, 384 PPU**, 동일한 한 변 **1.3333333 유닛**.
- 장식 외곽: 256px 기준 **(7,7), 242×242**. 최종 512px 기준 **(14,14), 484×484**, 여섯 면 모두 동일.
- 얼굴: 같은 고해상도 정면 원본을 동일한 좌표·크기에 배치. 피부·눈·입·금속·은백색 머리 픽셀은 보존하고 붉은 장비 부분에만 유형 색을 적용한다.
- 심볼: 같은 크기·좌표에 배치. 바탕 76px, 흰색 심볼 64px.
- 장식: 실제 `Tile_Path_Overlay_Asgard_FRAME`의 동일한 알파 형상을 공유하고 상태 색상만 바꾼다.

실제 바닥 그림의 현재 보이는 픽셀 범위는 (6,5), 244×242이고, 보정된 공통 장식은 (7,7), 242×242다. 이번 작업은 기존 패스 타일 파일을 수정하지 않고 **같은 캔버스·표시 배율과 공통 정사각형 장식 규격**에 몬스터 에셋을 맞췄다.

**Grid의 셀 간격 1.5와 타일 그림 크기 1.3333333은 다르다.** 이후 타일 그림과 같은 크기의 3D 큐브를 만들 때는 한 변 1.3333333을 기준으로 사용하면 된다.

## 게임 에셋

`Assets/4. Asset/4. Enemy/Asgard/CubeValkyrie/StateFaces_v1/`

- `Enemy_Valkyrie_Face_<Key>_v1.png`: 주 에셋 6장. Sprite Single, 384 PPU, 중앙 피벗, FullRect, 무압축, 밉맵 없음. 타일과 같은 정사각형 외곽 마스크를 적용해 바깥 여백은 투명하다. 기존 텍스처 GUID는 유지했다.
- `Layers/Portrait_<Key>.png`: 동일한 위치·형상의 캐릭터 레이어.
- `Layers/Decoration_<Key>.png`: 동일한 크기·형상의 장식 레이어.
- `Layers/Background_<Key>.png`: 배경 레이어. 세 레이어 모두 같은 512px 캔버스와 384 PPU로 설정되어 같은 위치·배율로 겹칠 수 있다.
- `Textures3D/Enemy_Valkyrie_Face_<Key>_v1.png`: 3D 큐브용 불투명 Texture Default 대안 6장. 그림 배치는 스프라이트와 동일하며 투명 외부만 배경색으로 채웠다. Opaque/Unlit 재질에 연결할 수 있다.
- `Enemy_Valkyrie_StateFaces_Atlas_v1.png`: 1536×1024, 3열×2행. 위 회복·방어·이동, 아래 행동·자물쇠·모래시계.
- 자물쇠·모래시계의 개별 흰색 심볼은 같은 폴더에 유지했다.

## 확인 자료

- `overview.png`: 수정한 여섯 면.
- `path-fit-preview.png`: 실제 패스 타일·동일 크기 장식·몬스터 면 비교.
- `preview.html`: 수정한 에셋으로 갱신한 큐브 부착 미리보기.
- `manifest.json`: 캔버스·PPU·월드 크기·레이어·배치·파일 SHA256 기록.
- `export-validation.txt`: 6면 외곽·얼굴/장식 알파 동일성, 장비 밖 원본 픽셀 보존, 심볼 배치 검사 통과.
- `before-path-fit/`: 크기 수정 전 PNG·메타데이터·문서 백업.

`Build-State-Faces.cjs`는 현재 보정 빌더 `Normalize-PathTile.cjs`를 실행한다. 정면 원본의 같은 좌표를 크기 조정하고, 장비 색을 매핑하며, 패스 타일 장식·배경·심볼을 합성한다. 이번 크기 보정에서는 이미지를 새로 생성하지 않았다. 이전 내장 image_gen 제작 기록은 `prompts.json`, `generation-manifest.json`, `generation/`, `source/`에 보존했다. 이전 빌더는 `Build-State-Faces.before-path-fit.cjs`다.

수정한 전체 시안과 실제 패스 타일 비교 이미지를 시각적으로 검토했다. 실제 Unity 프리팹·씬·기존 타일 크기는 변경하지 않았다. Unity 편집기에서 이번 스프라이트 임포트와 실제 게임 화면을 확인하는 작업은 수행하지 않았다.
