# 발키리 정면 · 6면 상태 에셋

기존에 승인된 타락한 발키리의 정면을 바탕으로 상태별 색과 흰색 심볼을 적용한 여섯 장이다. 기각된 정수리·갑옷판 시안이나 측면·후면 그림은 사용하지 않았다.

| 상태 | 색 | 흰색 심볼 | 파일 키 |
|---|---|---|---|
| 자가치유 | 빨강 | 회전 화살표 + 십자 | SelfHeal |
| 방어 | 노랑 | 방패 | Defense |
| 이동력 | 하늘색 | 빠른 발 | Mobility |
| 행동력 | 초록 | 번개 | Action |
| 능력 비활성화·약점 | 회색 | 자물쇠 | Locked |
| 피해·버프·디버프 적용 차단 | 보라 | 모래시계 | Hourglass |

위 효과 명칭은 그림의 상태 구분용이다. 능력과 피해 판정 코드는 이번 에셋 작업에 포함하지 않았다.

## 게임용 파일

`Assets/4. Asset/4. Enemy/Asgard/CubeValkyrie/StateFaces_v1/`에 저장했다.

- `Enemy_Valkyrie_Face_<Key>_v1.png`: 개별 면 6장, **512×512 RGBA**. 같은 정면 구도에 프레임·보석·깃털·배경 색과 상태 심볼을 적용했다.
- `Enemy_Valkyrie_StateFaces_Atlas_v1.png`: **1536×1024**, 3열×2행. 위 회복·방어·이동, 아래 행동·자물쇠·모래시계.
- `Symbol_Locked_White_v1.png`, `Symbol_Hourglass_White_v1.png`: 새로 추가한 흰색 문양. 기존 네 문양은 `Emblems_v1/`를 재사용한다.

면 텍스처는 3D 큐브 재질에 연결하기 편하도록 **Default Texture, Clamp, 무압축, 밉맵 없음**으로 설정했다. 그림 밖 투명 여백 대신 해당 면의 옅은 배경색으로 캔버스를 채워 **512×512 전체가 불투명**하다. Unity의 큐브 면 재질에서 검은 틈이나 투명 구멍으로 보이는 것을 방지하기 위한 구성이다. 심볼은 어두운 유형색 원형 바탕에 흰색으로 배치해 밝은 초상 배경에서도 구분되게 했다.

## 미리보기와 원본

- `overview.png`: 여섯 장을 한눈에 보는 그림.
- `preview.html`: 독립 미리보기. 32/48/64px 크기 비교와 6면 큐브 회전 버튼을 제공한다.
- `faces/`: 최종 PNG 복사본 6장.
- `source/`: 이미지 원본. 회복은 기존 승인된 빨간 면, 나머지는 색상 변형 생성 원본이다.
- `symbols/`: 여섯 문양의 SVG와 투명 흰색 PNG.
- `manifest.json`: 파일·GUID·색·심볼·권장 면 배치·SHA256 대응표.

권장 면 배치는 +Z 회복, -Z 방어, +X 이동, -X 행동, +Y 자물쇠, -Y 모래시계다. 실제 큐브의 UV 방향과 카메라에 맞춰 바꿀 수 있다.

## 제작 방식과 확인

색상 변형 다섯 장은 **내장 image_gen 도구**로 각각 제작했다. 승인된 빨간 정면 타일을 편집 대상으로, 원래의 고해상도 정면 초상을 세부 참고로 사용했다. 회복 면은 승인된 기존 그림을 재사용했다. `prompts.json`에 최종 프롬프트 세트, `generation-manifest.json`과 `generation/`에 실제 프롬프트·참고 이미지·원본 경로·정규화 좌표를 기록했다. 자물쇠·모래시계는 기존 단색 문양 계열을 따라 SVG로 작성했다.

`Build-State-Faces.cjs`는 생성 그림의 투명 여백을 정리하고 같은 면 크기에 맞춘 뒤 정확한 흰색 심볼과 바탕을 합성한다. 원본 여섯 장과 최종 전체 그림을 시각적으로 검토했다. 여섯 면이 512×512이며 모든 픽셀의 알파가 255인 것도 확인했다.

이번 결과물은 이미지 에셋과 브라우저의 큐브 부착 미리보기다. 실제 Unity 프리팹 생성·재질 연결·능력 로직 변경은 수행하지 않았다. Unity 편집기 임포트와 실제 게임 카메라에서의 최종 확인은 연동 단계에 남아 있다.
