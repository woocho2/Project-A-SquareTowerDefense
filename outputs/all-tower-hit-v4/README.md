# 일반 타워 타격 이펙트 28종 v4

사용자가 선택한 범위: **일반 14문양의 단일·광역 타격만**. 검 v3의 두 효과를 재사용하고 나머지 26종을 새로 제작했다. 일반 공격 5티어씩, 총 140개 타워 데이터 행에 적용된다.

- 각 효과 30프레임, 12FPS, 2.5초. 총 840개 프레임 셀.
- 투명 RGBA, 6열 × 5행, 셀 256×256, 256PPU. 애니메이터 1배속, 반복 꺼짐, 2.5초에 `DestroyEffect` 이벤트로 회수.
- 문양별로 빠른 접촉·타격, 파동·조각, 잔상 소멸이 이어진다. 기획 4장의 공격 정체성과 색을 반영했다.
- 아군을 강화하는 도끼·바람의 단일 스킬 표현은 적을 맞히는 타격에 맞게 베기·돌풍으로 해석했다.

## 보기와 에셋

- `preview.html`: 이미지가 포함된 단독 인터랙티브 미리보기. 문양 선택, 단일·광역 동시 재생, 프레임 탐색, 밝고 어두운 배경, 착탄 위치 표시.
- `overview.png`: 28종의 대표 프레임을 한 장에 모은 그림.
- `gif/`: 새 효과 26종의 재생 미리보기. GIF의 10ms 시간 단위에 맞춰 80/80/90ms 패턴으로 총 2500ms를 구성했다. Unity와 HTML은 12FPS를 사용한다.
- 새 게임 에셋: `Assets/4. Asset/6. Effect/TowerHits_v4/`. 각 효과마다 PNG, 30개 스프라이트 분할 메타, 애니메이션, 컨트롤러, 프리팹을 저장했다.
- 검: `Assets/4. Asset/6. Effect/SwordHit_v3/`.

## 제작 기록과 검증

**내장 image_gen 도구**로 이미지를 제작했다. `prompts.json`에 26개 생성 프롬프트, `generation/`에 실제 사용한 검 스타일 참고 이미지와 원본 저장 경로를 기록했다. 결과 원본은 `source/`에 저장했다. 원본 이미지를 코드로 그리는 방식으로 대체하지 않았다.

`Build-Effects.cjs`는 생성 이미지의 투명 여백에서 프레임을 분리하고 동일 스케일로 패킹한다. 원본의 행 간격이 고르지 않은 경우를 처리하며, 어둠 단일의 긴 가시는 열별 분리 위치를 사용해 보존했다. 피벗은 밝은 타격 중심 기준으로 등록했다. 방향을 따라 회전하는 창은 전방의 충돌 지점에 맞췄다. 모든 분할 위치·피벗·GUID는 `asset-manifest.json`에 기록했다.

검증 완료:

- `export-validation.txt`: 28개 RGBA 아틀라스, 840셀, 새 26개 시트의 투명 셀 경계·원본 분리·프레임 진행, 30프레임·2500ms GIF, 비공격 이펙트 연결 보존.
- `unity-validation.txt`: 분리된 Unity 6000.3.9f1 프로젝트에서 모든 28개 프리팹의 실제 라이브러리 참조, 30개 스프라이트 순서·피벗, 12FPS·2.5초 길이, 1배속, 회수 이벤트, **840개 실제 Animator 프레임 전환** 확인. CSV 140개 공격 타워 행과 실제 EffectManager의 라이브러리 연결도 확인했다.

실제 전투 화면의 겹침과 크기를 GPU로 캡처하는 검사는 하지 않았다. 효과는 기존 공격 범위와 전역 이펙트 배율을 그대로 따른다.
