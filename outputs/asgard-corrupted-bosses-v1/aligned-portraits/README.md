# 보스 큐브 면의 초상 위치 통일

각 보스의 첫 번째 자가치유 초상만 공통 원본으로 사용한다. 여섯 개별 그림을 이동·확대해서 맞추는 방식에서, 하나의 그림을 동일한 512×512 좌표에 고정하고 장비 포인트 색상만 변경하는 방식으로 바꿨다. 얼굴·표정·머리카락·어깨와 모든 알파 값은 여섯 상태에서 정확히 같다.

내장 imagegen 편집으로 빨간 장비의 선택 마스크를 제작했다. `mask-prompt.txt`가 최종 프롬프트, `equipment-mask-generated.png`가 생성본이다. `Align-Portraits.ps1`은 생성 마스크의 미세한 위치 오차를 허용하는 범위 안에서 원본의 실제 붉은 장비 색을 선택한다. 피부·금속·머리·눈은 선택하지 않고, 동일 원본 장비를 여섯 상태 색으로 변환한다. 실제 최종 선택 마스크와 공통 초상도 보스별 PNG로 보관했다.

Assets에서는 기존 아틀라스 PNG 두 장만 교체했다. 메타·GUID·스프라이트 위치·재질·프리팹은 동일하며, 연결 파일의 변경 전 SHA256은 `connection-before-hashes.json`에 있다. `verification.txt`는 12개 초상의 동일 알파와 장비 외 픽셀 보존 검사다. 최종 아틀라스와 작업본의 SHA256 일치도 확인했다. Unity는 실행하지 않았다.

`preview.png`는 전체 비교, `before/`는 수정 전 작업본이다. 재생성할 때는 상위 `Build-Bosses.ps1` 다음 `Save-Assets.ps1`을 실행한다.
