# 가면 캐릭터 큐브형 SD 재구성 시안

사용자가 보낸 검은 머리·검정/금색 반가면·보라색 마법·흰 털 장식 캐릭터의 특징을 단순한 네모 머리 형태로 재구성했다.

최종 검토 파일: `MaskedCharacter_Cube_Concept_v2.png`. 얼굴 비중을 늘리고 머리카락과 가면을 큰 덩어리로 정리했다. 마법 문양은 아래 모서리에 작게 배치했다. 내장 imagegen으로 제작한 투명 배경 디자인 시안이다.

`prompt.txt`와 `draft.png`는 첫 재구성 결과로, 여전히 머리와 가면의 비중이 커서 재작업했다. `prompt-refinement.txt`가 최종 제작 프롬프트다. 최종 생성은 원본 캐릭터의 특징을 텍스트로 지정하여 새로 그렸다.

정확한 제작용 알파 마스크 적용이나 256px 패킹은 아직 수행하지 않은 시안이다. Assets와 런타임 연결은 변경하지 않았다.
