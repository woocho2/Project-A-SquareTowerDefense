# 도끼 B · 거친 용병: 검 기준 얼굴 비율 수정

사용자는 B · 거친 용병의 인상을 선택했고, 검 타워와 얼굴 비율을 맞추도록 요청했다. 이전 비교본은 눈높이만 맞췄고 실제 얼굴의 세로 길이는 길게 남아 있었으므로 기준 충족본으로 사용하지 않는다.

내장 image_gen으로 검 B 원본을 얼굴 구도 기준으로 삼아 다시 그렸다. 중년 인상, 갈색 머리·덥수룩한 수염, 붉은 눈, 거친 머리와 도끼·모피·가죽 복장은 유지하면서 눈 크기와 눈 아래 얼굴의 비율을 수정했다.

- Axe_Base_B_Proportion_Corrected.png: 최종 비율 수정 시안.
- Sword_Axe_Proportion_Comparison.png: 검과 도끼를 동일 배율·좌표로 배치한 비교본.
- Eye_Check.json: 실제 홍채 색상 영역으로 측정한 눈 위치와 간격.
- Validation.json: 배치 및 측정 결과와 검수 범위.
- final-prompt.json: 선택된 이미지와 최종 생성 프롬프트.

비교에는 검 기준 Reference.json의 같은 공통 배율 480/1254와 같은 오프셋, 같은 하단 기준선을 사용했다. 이미지별로 별도 확대·축소하거나 얼굴을 비틀지 않았다.

실제 붉은 홍채 중심으로 대조한 결과, 512px 배치 기준 눈높이 중심 차이는 약 0.01px, 눈 사이 간격 차이는 약 0.66px였다. 색상 중심 검사는 눈 위치의 비교이며 얼굴 전체가 픽셀 단위로 같다는 의미는 아니다. 도끼는 별도 인물이며 수염 때문에 실제 턱선이 가려지므로 턱 위치를 직접 측정했다고 주장하지 않는다. 전체 얼굴·상체 비율은 동일 배율 비교본으로 육안 확인했다.

거친 용병의 기본 인상은 선택됐지만 이번 비율 수정본은 시각적 확인을 위한 시안이다. 아직 도끼의 네 전직이나 게임 아틀라스에는 반영하지 않았다.
