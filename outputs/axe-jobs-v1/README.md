# 도끼 기본형 기반 네 전직 시안

사용자가 직접 첨부해 선택한 `../axe-base-approved/Axe_Base_Approved.png`를 동일 인물의 네 전직으로 수정했다. 이전에 따로 만들었던 다른 비율 수정본으로 바꾸지 않았다. 모든 창작 이미지 수정은 내장 image_gen으로 수행했으며 전체 프롬프트는 prompts.json, 생성 원본 경로와 팔레트는 sources.json에 기록했다.

| 위치 | 이름 / 역할 | 머리·수염색 | 눈색 | 의상 중심색 |
| --- | --- | --- | --- | --- |
| 왼쪽 위 | 바이킹 / 광역 | 갈색 | 빨강 | 빨강 |
| 오른쪽 위 | 버서커 / 타겟 | 짙은 남색 | 파랑 | 파랑 |

| 오른쪽 아래 | 집행관 / 디버프 | 흰색 | 보라 | 보라 |

## 결과물

- raw/: 생성된 1254×1254 투명 원본 네 장. 생성 파일을 그대로 복사했다.
- cells/: 공통 좌표와 배율로 배치한 512×512 이미지 네 장.
- Axe_Classes_Preview.png: 이름을 표시한 2×2 비교본.
- Axe_Classes_Atlas_Draft.png: 배경과 이름표가 없는 1024×1024 RGBA 아틀라스 초안.
- Face_Overlay.png: 각 전직 얼굴과 원본을 50%로 겹친 검수 이미지.
- Face_Landmarks.csv, Validation.json: 실제 위치 대조 결과.

사용자가 이 네 전직 시안의 아틀라스 저장을 승인했다. 기존 도끼 아틀라스의 .meta와 스프라이트 ID를 유지해 `Assets/4. Asset/2. Tower/TowerCharacter/Axe_atlas.png`로 반영한다. 반영 전 백업과 파일·참조 검수 결과는 `../axe-atlas-apply-v1/`에 기록한다. 이 폴더의 `Validation.json`은 시안 제작 당시의 검수 기록이다.

## 비율 검수

네 원본은 모두 1254×1254다. 첨부 원본의 얼굴·머리스타일·수염 실루엣·표정을 기준으로 유지했고 색상과 전직 의상을 바꿨다. 배치에는 모든 이미지에 공통 배율 480/1254, X 오프셋 16, Y 오프셋 약 47.167464와 하단 기준선 482를 적용했다. 이미지별 확대·축소, 얼굴 비틀기나 별도 워핑은 하지 않았다.

원본과 네 전직 각각의 왼눈·오른눈·코·입/콧수염·수염 끝·왼볼·오른볼의 7개 패치, 총 28곳을 읽기 전용 윤곽 상관 비교로 대조했다. ±24 원본 픽셀 범위에서 가장 잘 맞는 위치를 찾고, 이동량에 공통 배율을 곱해 512×512 셀의 픽셀 단위로 환산했다.

확인된 최대 위치 차이는 512×512 기준 약 0.86px, 최소 윤곽 상관은 0.6543이다. 머리·수염 색상 변경으로 명암 대비가 달라지므로 전체 이미지의 픽셀 동일성을 뜻하지 않는다. 수염 끝을 확인한 것이며 가려진 실제 턱선을 측정했다고 하지 않는다. 겹친 얼굴과 전체 비교본도 육안 확인했다.

Compare-Faces.cs는 원본과 결과를 읽기만 하는 비교 도구다. Build-Preview.ps1은 원본을 보존하면서 공통 규격의 비교본과 초안 아틀라스를 배치한다. 스칼드 원본 모서리 한 점의 알파는 1/255이므로 완전 불투명 배경과 구분하여 미세 알파를 허용했고, 실제 배치 셀에는 투명 여백을 둔다.
