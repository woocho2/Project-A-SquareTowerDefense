# 단일 총알 Idle / Flight 모션 v2

일반 14문양의 단일 총알을 현재 타격 이펙트의 색·형태에 맞춰 새로 제작하고 게임에 연결했다. 각 문양마다 **Idle 8프레임 + Flight 8프레임**, 12FPS, 약 0.667초 반복이다. 총 28개 모션·224프레임이다.

## 게임 동작

- 생성·풀에서 꺼내기: Idle 첫 프레임으로 초기화.
- 타워 주변 위성 대기(`PrepareAsSatellite`): Idle 반복. 원래처럼 이동·명중 판정과 트레일 방출은 발사까지 대기한다.
- 발사(`Launch`): 같은 프레임에 Flight 첫 프레임으로 전환하고 반복한다. 기존 비행 방향·속도·추적·타격 처리를 사용한다.
- 풀 회수·재사용: Flight 상태와 시간을 초기화하고 Idle로 돌아간다.

`ProjectileHit2D.cs`는 전용 이미지이며 `IsFlying` 불리언을 갖는 컨트롤러에만 새 모션 전환을 적용한다. 기존 광역·특수 투사체의 컨트롤러는 유지한다. 도끼와 방패는 기존 코드의 회전 투척을 유지하며, 그림에 추가로 큰 회전을 중복해서 넣지 않았다.

## 저장과 연결

- 에셋: `Assets/4. Asset/3. Projectile/AnimatedSingle_v2/`.
- 문양별 `Bullet_<Emblem>_Motion_v2.png`: 4열 × 4행, 1024×1024 RGBA, 256px 셀 16개. 위 두 행은 Idle, 아래 두 행은 Flight.
- `*_Idle.anim`, `*_Flight.anim`, `*.controller`: 각각 8개 키, 12FPS, 반복 켜짐. 수명 종료 이벤트가 없는 비행 루프다. 실제 수명과 회수는 기존 투사체 코드가 관리한다.
- `Assets/Resources/Projectiles/201.prefab`부터 `214.prefab`: 새 시트와 Idle/Flight 컨트롤러 연결. 모든 티어가 같은 문양의 풀을 공유한다.
- 기존 총알 그림과 프리팹 GUID는 보존했다. 수정 전 프리팹은 `before/`에 저장했다.

스프라이트는 256PPU이며 타격점에 가까운 몸체의 위치를 맞춰 Idle·Flight 사이를 정리했다. 기존 프리팹 배율 1과 GlobalProjectileManager의 전역 배율 0.5를 사용한다. 잔상·파티클 색도 새 그림의 문양별 색에 맞췄다. 피해·속도·수명·공격 횟수·충돌 반경을 바꾸지 않았다.

## 확인

`preview.html`은 이미지가 포함된 독립 미리보기다. 문양별 Idle과 Flight을 동시에 보고, 아래에서는 대기 → 비행 → 현재 타격 이펙트의 흐름을 확인할 수 있다. 일시정지·프레임 탐색·밝고 어두운 배경 전환을 지원한다. `overview.png`는 28개 모션의 대표 그림, `gif/`는 반복 재생 파일이다. GIF는 10ms 단위 제한에 맞춰 670ms이며 Unity·HTML은 8/12초를 사용한다.

## 제작·검증 기록

**내장 image_gen 도구**로 28개 모션 시트를 각각 제작했다. 현재 타격 이펙트를 스타일 참고로 사용했고, Flight은 해당 문양의 완성된 Idle 시트를 추가로 참고해 본체를 맞췄다. `prompts.json`에 기본 프롬프트, `generation/`에 실제 최종 프롬프트와 참고 이미지·원본 경로를 기록했다. 원본은 `source/`에 보존했다. `Build-Sheets.cjs`는 원본을 분리·패킹하며 효과를 코드로 다시 그리지 않는다.

`ProjectileMotionBuild.cs`는 분리된 Unity 6000.3.9f1 프로젝트에서 네이티브 클립·컨트롤러·프리팹을 생성하고 **실제 플레이 모드**에서 검사했다. 14종 모두 실제 ProjectileObjectPool2D로 생성·대기·발사·회수·재사용했고, 각 16개 프레임과 반복 경계, 즉시 Flight 전환, 재사용 시 Idle 첫 프레임 복구, 원래 표시 배율을 확인했다. 검증된 파일을 실제 프로젝트에 복사했으며 프리팹의 SHA256 일치도 확인했다.

- `playmode-validation.txt`: 14종 런타임 모션·풀 수명주기 검증 통과.
- `export-validation.txt`: 14개 RGBA 시트, 224개 고유 프레임, 투명 셀 경계와 28개 GIF 검사 통과.
- 전체 게임 C# 컴파일 통과. 실제 전투 장면의 GPU 화면 캡처 검사는 하지 않았다.

플레이 모드를 종료하고 다시 실행하면 새 애니메이션이 연결된 프리팹으로 총알 풀이 구성된다.
