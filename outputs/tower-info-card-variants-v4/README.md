# 타워 정보 카드 배치 시안 v4

이름을 얼굴 위에 배치하고, 많은 스탯을 어떻게 나눠 보여줄지 비교하기 위한 세 가지 시안입니다. 내장 imagegen으로 각각 생성했습니다. Unity에 연결하기 전의 이미지 시안이며 수치는 배치 검토용 예시입니다.

| 시안 | 구성 | 특징 |
| --- | --- | --- |
| [A · 초상화 중심형](a-portrait-focus.png) | 큰 초상화, 핵심 스탯 3개, 스킬 버튼 2개 | 캐릭터와 수집 카드 인상이 가장 강함 |
| [B · 스탯 균형형](b-six-stats.png) | 초상화, 2열 × 3행 기본 스탯, 스킬 버튼 | 공격 관련 수치를 한눈에 비교하기 좋음 |
| [C · 스킬 요약형](c-skill-summary.png) | 큰 초상화, 핵심 스탯 3개, 스킬 요약 행 2개 | 수치와 공격 방식을 함께 읽기 좋음 |

추천은 C입니다. 핵심 스탯은 항상 보이고, 스킬 행을 눌러 카드가 뒤집히면 상세 설명을 보여주는 흐름으로 확장할 수 있습니다. 나머지 능력치는 하단 전체 능력치 진입점에 배치하는 제안입니다. 이 이미지에는 실제 회전 동작이 구현되어 있지 않습니다.

세 시안은 1024 × 1536 PNG이며 이름, 초상화, 수치, 스킬 진입점이 모두 잘리지 않고 보이는지 확인했습니다. B의 행동력 아이콘은 이동력으로 읽힐 수 있으므로 실제 제작 시 프로젝트 공통 시계 아이콘으로 통일하는 편이 좋습니다. 시안의 아이콘 그림은 실제 아틀라스를 대체하지 않습니다.

캐릭터 참조: [기존 히어로 타워](../character-art-audit-v1/unity-rendered-towers/Tower_1101.png).

생성 방식: 내장 imagegen, 로컬 히어로 타워 이미지를 참조로 사용. 각 최종 프롬프트: [A](a-portrait-focus-prompt.txt), [B](b-six-stats-prompt.txt), [C](c-skill-summary-prompt.txt).
