# 검 계열 기본 캐릭터: B · 냉정한 천재

이 전직 규칙은 무기군(검·도끼·활·창·방패·해머)에만 적용한다. 무기 문양마다 별도의 기본 캐릭터를 정하고, 같은 문양 안의 네 역할을 동일 인물의 전직으로 표현한다. B는 검 계열의 기본 캐릭터다.

원소군은 피닉스·라이트닝 울프처럼 각각 독립된 캐릭터나 괴수가 될 수 있다. 동일 인물·얼굴·체형이나 사람의 머리색·눈색 전직 규칙을 적용하지 않는다. 공통 기준은 그림체와 이미지·아틀라스 규격이다. 전체 범위는 `../tower-character-rules.md`에 기록했다.

사용자가 선택한 원본은 `Sword_Base_B_Approved.png`이다. 이미지 원본을 그대로 복사했으며 `Master.sha256`으로 동일성을 확인했다.

A~C는 프롬프트로 비율을 요청한 탐색 시안이며, 실제 얼굴 크기가 동일하게 정렬된 이미지가 아니다. B만 기본 얼굴과 머리스타일의 기준으로 사용한다.

`Reference.json`에는 원본 좌표의 수동 얼굴 기준점, 512×512 셀로 옮길 때의 공통 배율·위치, 전직별 색상 규칙과 검수 절차를 기록했다. 수동 기준점은 정렬 보조이며 얼굴 형태의 최종 기준은 승인된 원본 이미지다.

- 광역: 갈색 머리 / 빨간 눈 / 빨강 중심 의상
- 타겟: 짙은 남색 머리 / 파란 눈 / 파랑 중심 의상
- 버프: 검은 머리 / 노란 눈 / 노랑·금색 중심 의상
- 디버프: 흰 머리 / 보라 눈 / 보라 중심 의상

네 전직은 동일 인물이다. 얼굴형·이목구비·표정·기본 머리스타일·체형을 유지하고 머리색·눈색·직업별 의상 및 장식을 바꾼다. 티어별로 캐릭터를 다시 그리지 않는다.

머리 장식이나 모자 크기를 기준으로 캐릭터 전체를 축소하지 않는다. 얼굴 기준점에 맞춰 하나의 공통 배율과 위치를 사용한다. 배경·이름표 제거 후에도 눈·턱 위치와 하단 기준선을 다시 대조한다.

생성 결과는 원본과 얼굴을 겹쳐 눈·턱·코·입·머리선을 대조한다. 눈과 머리의 색 차이는 허용하되, 얼굴 크기나 이목구비가 달라진 경우 아틀라스에 반영하기 전에 수정한다. 프롬프트에 동일 비율을 적는 것만으로 정렬 완료라고 판단하지 않는다.

현재 완료 범위: B 원본 확정과 기준 기록, B 기반 4전직 제작 및 실제 얼굴 위치 대조, 사용자 승인 후 게임 아틀라스 적용. 결과는 `../sword-b-jobs-v1/`에 있다. 공통 배율로 배치하고 총 28개 얼굴 패치를 원본과 대조했으며, 512×512 기준 확인된 최대 위치 차이는 약 0.54px였다. 적용된 에셋은 `Assets/4. Asset/2. Tower/TowerCharacter/Sword_Atlas.png`이며 기존 GUID와 스프라이트 ID를 유지했다.
