# 적 데코레이션 중립색 베이스와 공통 상태색

`Assets/4. Asset/4. Enemy/Enemy_Decoration.png`를 흰색·회색으로 바꿨다. 기존 레이어 생성 스크립트에서 원본 RGB의 최대값을 회색 밝기로 내보내므로 명암 깊이를 유지하고 색상만 제거한다. 모든 알파 값과 픽셀 위치는 그대로다.

셰이더의 별도 Decoration Color와 Recolor Decoration 설정을 제거했다. `State Color (Equipment Mask + Decoration)` 하나가 캐릭터의 장비 마스크와 테두리에 함께 적용된다. 저장된 프로퍼티 키는 기존 `_EquipmentColor`를 사용하며, 테두리는 자체 알파를 마스크로 삼아 중립색 텍스처에 같은 색을 곱한다. 새 테두리 마스크 PNG는 중복 생성하지 않았다.

18개 상태 재질에서 장비 색 적용을 모두 켰고, 같은 상태의 세 캐릭터가 동일한 팔레트를 사용함을 검사했다. 배경은 기존의 옅은 상태색을 유지한다. 제작/연결 스크립트와 18상태 CPU 미리보기는 `outputs/enemy-cube-layers/`에서 갱신했다. 검사는 `verification.txt`, 변경 전 파일은 `before/`에 있다.

다른 캐릭터 텍스처·마스크·외형 설정·메시·메타의 해시는 유지했다. Unity는 실행하지 않았으므로 셰이더 컴파일과 실제 렌더링 검증은 사용자가 수행한다.
