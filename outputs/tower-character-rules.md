# 타워 캐릭터 제작 규칙

## 무기군: 동일 인물의 네 전직

적용 대상은 검·도끼·활·창·방패·해머다. 문양마다 기본 캐릭터 한 명을 정하고, 해당 문양의 광역·타겟·버프·디버프를 같은 인물의 전직으로 제작한다.

같은 문양의 네 전직은 얼굴형·이목구비·표정·기본 머리스타일·체형·얼굴 크기를 유지한다. 머리색·눈색·의상·무기·직업 장식으로 전직 차이를 표현한다.

| 역할 | 머리색 | 눈색 | 디자인 중심색 |
| --- | --- | --- | --- |
| 광역 | 갈색 | 빨강 | 빨강 |
| 타겟 | 짙은 남색 | 파랑 | 파랑 |
| 버프 | 검정 | 노랑 | 노랑·금색 |
| 디버프 | 흰색 | 보라 | 보라 |

검 계열은 `sword-base-character-b/Sword_Base_B_Approved.png`의 B · 냉정한 천재형이 기준이다. 검의 기준 얼굴을 다른 무기 문양의 동일 인물로 강제하지 않는다.

## 원소군: 개별 캐릭터와 괴수

적용 대상은 불·물·대지·바람·얼음·전기·빛·어둠이다. 각 콘셉트마다 독립된 캐릭터나 괴수로 제작할 수 있다. 예: 피닉스, 라이트닝 울프.

원소군에는 동일 인물의 전직, 같은 얼굴·체형, 사람의 머리색·눈색 규칙을 강제하지 않는다. 종과 실루엣, 신체 구조와 고유 색상은 개별 콘셉트에 맞춘다.

## 공통 제작·검수

- 기존 게임의 그림체, 윤곽선과 채색·명암을 일관되게 유지한다.
- 캐릭터당 512×512, 2×2 아틀라스 1024×1024, 투명 배경과 최소 16px 여백을 사용한다. 이름표와 배경은 실제 에셋에 넣지 않는다.
- 아틀라스 순서는 왼쪽 위 광역, 오른쪽 위 타겟, 왼쪽 아래 버프, 오른쪽 아래 디버프다.
- 무기군은 기준 원본과 실제 얼굴 크기·눈·턱 위치를 겹쳐 대조한다. 프롬프트로 동일 비율을 요청한 것만으로 고정 완료라고 하지 않는다. 모자나 장식 때문에 얼굴을 축소하지 않는다.
- 원소군은 사람 얼굴 기준점 대신 각 캐릭터의 중심·실루엣·셀 내 크기와 잘림을 검수한다.
- 개별 시안과 비교본 확인 후 아틀라스에 반영하며, 기존 에셋 교체 시 GUID와 스프라이트 ID를 유지한다.
- 티어는 기존 타워 외형으로 구분하며 캐릭터 그림을 티어별로 다시 만들지 않는다.
