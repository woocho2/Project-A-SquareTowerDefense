# 스플래쉬 오브 · 무기군 수정과 Idle / Flight 연동

일반 스플래쉬 타워 14종의 오브 그림과 대기·비행 모션을 실제 프리팹에 연결했다. 검·도끼·활·창·방패·망치 6종은 현재 단일 총알과 타격 이펙트의 색·형태에 맞춰 수정했다. 원소군 8종은 기존 PNG를 그대로 사용한다.

## 그림

**내장 image_gen 도구**로 무기 오브 6종을 각각 수정했다. 기존 오브를 편집 대상으로, 완성된 단일 총알 그림을 스타일 참고로 사용했다. 검은 분홍빛 검기·꽃잎, 도끼는 주황빛 초승달 날, 활은 초록빛 활과 화살, 창은 남색 장창과 붉은 장식, 방패는 파랑·금색 원형 방패, 망치는 황금빛 머리와 충격 조각을 오브 내부에 담았다. 원본 그림은 보존했다.

- 최종 그림: `Assets/4. Asset/3. Projectile/AnimatedSplash_v1/Splash_<Weapon>_Orb_v2.png`.
- 생성 원본: `source/`. 최종 PNG와 원본의 SHA256 일치를 확인했다.
- 실제 최종 프롬프트·참고 이미지·생성 파일 경로: `prompts.json`, `generation/`.
- 원소군 그림: 기존 `Assets/4. Asset/3. Projectile/Cartoon/Splash/`.
- 전체 그림: `overview.png`. 문양별 수정 전후와 모션 비교: `preview.html`.

## 모션과 게임 연결

`Orb_Idle.anim`, `Orb_Flight.anim`, `Orb_Motion.controller`는 `AnimatedSplash_v1/`에 저장했다. 14종이 같은 모션을 공유하며 각 오브 그림은 프리팹별로 다르다. 각 상태는 **8단계, 12FPS, 8/12초 반복**이다. 경계를 닫는 9번째 키는 첫 단계와 동일하다.

- Idle: 그림만 약 ±4% 맥동하고, ±2.4도 흔들리며 은은하게 빛난다.
- Flight: 진행 방향으로 조금 늘어나고 수축·팽창하며, 기존 잔상과 파티클을 방출한다.
- 생성·위성 대기는 Idle로 시작하고, 발사 시 같은 프레임에 Flight으로 전환한다. 풀에서 다시 꺼내면 Idle 첫 상태로 초기화한다.

이 모션은 그림의 크기·각도·투명도를 네이티브 Unity 애니메이션 곡선으로 움직인다. 총알 루트 대신 `OrbVisual` 자식만 애니메이션 처리해 이동 좌표·발사 방향·전역 배율과 충돌하지 않는다. 스프라이트 탐색과 잔상·파티클 설정도 자식 렌더러를 지원하도록 `ProjectileHit2D.cs`의 세 곳을 수정했다.

`Assets/Resources/Projectiles/101.prefab`부터 `114.prefab`에 연결했고, 모든 티어가 기존 문양별 풀을 공유한다. 프리팹 GUID, 수명, 충돌 반경, 물리 설정, 광역 피해와 타격 이펙트는 보존했다. 수정 전 프리팹은 `before/`에 저장했다.

## 검증

Unity 6000.3.9f1의 분리된 검증 프로젝트에서 네이티브 클립·컨트롤러·프리팹을 생성했다. 실제 플레이 모드의 ProjectileObjectPool2D로 14종 모두 생성·대기·발사·회수·재사용을 검사했다. 각 16개 모션 단계와 반복 경계, 즉시 상태 전환, 자식 그림·잔상 설정, 루트 위치·크기·방향 유지, 재사용 초기화가 통과했다. 단일 총알 14종의 기존 Idle / Flight도 회귀 검사를 통과했다.

- `playmode-validation.txt`: 실제 플레이 모드 검사 통과.
- `export-validation.txt`: 실제 프로젝트의 14개 프리팹 연결, GUID와 보존 값, 원본 그림, 투명도 및 미리보기 JavaScript 검사 통과.
- 전체 게임 C# 컴파일과 `git diff --check` 통과.

검증한 프리팹을 실제 프로젝트로 반영했다. 검증 프로젝트에 물 그림이 중복되어 Unity가 새 GUID를 부여한 경우에는 같은 PNG임을 SHA256으로 확인하고 실제 프로젝트의 원래 GUID로 참조를 복구했다. 이 매핑은 `asset-manifest.json`에 기록했다. 실제 전투 장면의 GPU 화면 캡처는 수행하지 않았다.

플레이 모드를 종료하고 다시 실행하면 새 프리팹으로 풀이 구성된다.
