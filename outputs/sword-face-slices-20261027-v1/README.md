# 검 타워 얼굴 슬라이스와 정보 패널 일러스트 분리

기존 Sword_Atlas.png 픽셀은 변경하지 않았습니다.
- 정보 패널: 기존 512×512 전체 슬라이스 52010~52013.
- 타워: 같은 PNG의 224×224 얼굴·상체 슬라이스 52014~52017. 표시 배율 약 2.286배.
- Face_Slices_Preview.png는 슬라이스를 512px로 확대해 보여주는 검토 이미지이며 게임에 새 PNG로 연결하지 않습니다.
- 다른 문양은 타워 전용 슬라이스가 없으면 기존 일러스트를 사용합니다.
- before/: 변경 전 코드, 카탈로그, 이미지 메타, 규칙 및 PNG 백업.
- validation.json: 슬라이스 좌표, 해시, 컴파일 및 참조 검증 결과.
- Unity 실제 플레이는 아직 확인하지 않았습니다.
