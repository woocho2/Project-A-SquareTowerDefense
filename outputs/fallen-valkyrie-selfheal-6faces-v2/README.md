# 자가치유형 발키리 · 윗면과 아랫면 시안

완성된 타워 스타일의 발키리 네 면에 윗면과 아랫면을 추가했다. 기존 빨간 타워 테두리와 256×256 면 규격을 사용한다. 정면·좌측·우측·뒷면 PNG는 이전 완성본을 그대로 복사했으며 SHA256 일치를 확인했다.

- **윗면:** 정수리에서 내려다본 검정·금색 투구, 은백색 머리, 붉은 깃털과 루비 보석. 정면 방향은 이미지의 아래쪽 가장자리이며 이마 보석이 그쪽에 있다.
- **아랫면:** 붉은 갑옷판과 중앙의 큰 흰색 자가회복 심볼. 유형 심볼은 앞서 완성한 `enemy-emblems-white-v1/png/SelfHeal.png`를 그대로 사용한다.

## 결과물

- `top-bottom-preview.png`: 위·아래 두 면을 크게 비교하는 시안.
- `overview.png`: 라벨이 있는 6면 전체.
- `preview.html`: 그림이 포함된 독립 미리보기. 위·아래·앞·뒤 보기와 90도 회전 버튼으로 큐브에 부착된 모습을 확인한다.
- `FallenValkyrie_SelfHeal_6Faces_v2.png`: 768×512 RGBA, 3열×2행, 셀 256px. 위 정면·좌측·우측, 아래 후면·윗면·아랫면.
- `faces/Top.png`, `faces/Bottom.png`: 완성된 개별 면.
- `layers/Top.png`, `layers/Bottom.png`: 기존 프레임을 합성하기 전의 그림 레이어. `Frame_Red.png`, `Background_Red.png`, `SelfHeal_White.png`도 포함한다.
- `source/`: 두 장의 생성 원본.
- `manifest.json`: 면 순서와 파일 SHA256, 제작 방식 기록.

## 제작 기록

투구 정수리와 붉은 갑옷판 그림은 **내장 image_gen 도구**로 각각 제작했다. 완성된 발키리의 정면과 후면을 참고해 투구·머리·깃털의 디자인을 맞췄다. `prompts.json`에 최종 프롬프트 세트, `generation-manifest.json`과 `generation/`에 실제 생성 파일 경로·참고 이미지·패킹 좌표를 저장했다.

`Build-Six-Faces.cjs`는 원본의 투명 여백을 정리하고 크기를 맞춰 기존 프레임과 배경을 합성한다. 갑옷판 중앙에는 기존의 정확한 흰색 자가치유 심볼을 겹친다. 캐릭터와 갑옷판을 코드로 다시 그리지 않았다. 원본·최종 2면·전체 6면을 시각적으로 검토했다.

이 결과물은 디자인 시안과 브라우저 미리보기다. 실제 Unity 프리팹·3D 큐브·굴림 로직에는 연결하지 않았다. 서로 다른 방향 그림이므로 실제 큐브에서 이음새와 카메라 각도를 확인하는 작업은 연동 단계에 남아 있다.
