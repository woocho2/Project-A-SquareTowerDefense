# B 기본 캐릭터 기반 검 계열 4전직 시안

선택된 B · 냉정한 천재형을 동일 인물의 네 전직으로 수정했다. 이미지 생성·수정에는 내장 `image_gen`을 사용했다. 프롬프트 전체는 `prompts.json`, 선택된 원본 경로와 역할은 `sources.json`에 기록했다.

| 위치 | 캐릭터 | 머리색 | 눈색 | 디자인 중심색 |
| --- | --- | --- | --- | --- |
| 왼쪽 위 | 검성 / 광역 | 갈색 | 빨강 | 빨강 |
| 오른쪽 위 | 검객 / 타겟 | 짙은 남색 | 파랑 | 파랑 |

## 결과물

- `raw/`: 생성된 1254×1254 투명 원본 네 장.
- `cells/`: 동일 기준 좌표와 배율로 배치한 512×512 이미지 네 장.
- `Sword_Classes_B_Preview.png`: 이름이 표시된 2×2 비교본.
- `Sword_Classes_B_Atlas_Draft.png`: 배경과 이름표가 없는 1024×1024 RGBA 아틀라스 초안.
- `Face_Overlay.png`: B 원본과 각 전직 얼굴을 50%로 겹친 검수 이미지.
- `Face_Landmarks.csv`, `Validation.json`: 실제 얼굴 위치 비교 결과.

사용자 승인 후 `Assets/4. Asset/2. Tower/TowerCharacter/Sword_Atlas.png`에 반영했다. 기존 아틀라스와 `.meta`를 함께 이름 변경하여 GUID와 스프라이트 ID 52010~52013, 카탈로그·프리팹 연결을 유지했다. 교체 전 파일은 `before-apply/`에 보관했다. 적용된 PNG는 승인된 초안과 해시가 동일하다.

## 얼굴 비율 검수

네 원본의 캔버스는 모두 1254×1254다. 모두 `../sword-base-character-b/Reference.json`에 기록된 같은 배율과 위치를 사용했고, 머리·장식 크기를 기준으로 개별 확대·축소하지 않았다. 원본 이미지를 얼굴에 맞춰 따로 변형하거나 비틀지도 않았다.

B 원본과 네 전직 각각의 왼눈·오른눈·코·입·턱·왼볼 윤곽·오른볼 윤곽, 총 28개 패치를 대조했다. 색 변화 영향을 줄이기 위해 밝기 기울기의 정규화 상관을 사용하여 ±24 원본 픽셀 범위에서 가장 잘 맞는 위치를 찾았다. 결과의 위치 차이는 원본 좌표의 차이에 실제 공통 배율 480/1254를 곱해 512×512 셀의 픽셀 단위로 환산했다.

확인된 최대 이동 차이는 512×512 기준 약 0.54px, 최소 윤곽 상관은 0.8093이다. 이는 확인한 패치의 위치 일치 측정이며 전체 이미지가 픽셀 단위로 동일하다는 뜻은 아니다. 겹친 이미지와 전체 비교본도 육안 확인했다.

`Compare-Faces.cs`는 읽기 전용 검수 도구다. `Build-Preview.ps1`은 원본을 보존하면서 공통 기준으로 비교본과 초안 아틀라스를 배치한다.
