# 자가치유형 타락한 발키리 · 타워 스타일 4면 시안

최종 요청에 맞춰 **정면 / 왼쪽 측면 / 오른쪽 측면 / 뒷면**만 제작했다. 위·아래 면은 이 결과물에 포함하지 않는다. 기존 타워처럼 머리와 어깨가 보이는 SD 초상, 연한 배경, 빨간 장식 테두리, 상단의 빨간 자가회복 심볼을 사용한다.

## 파일

- `overview.png`: 4면을 나란히 보는 완성 시안.
- `preview.html`: 독립 미리보기. 네 장과 3D 큐브의 옆면 부착 모양을 확인할 수 있다. 회전 버튼으로 각 방향을 볼 수 있으며 상·하 그림은 없다.
- `FallenValkyrie_SelfHeal_4Faces_v1.png`: 512×512 RGBA, 2×2 타일. 위 정면·왼쪽, 아래 오른쪽·뒷면. 각 셀 256×256.
- `faces/{Front,Left,Right,Back}.png`: 배경·초상·빨간 테두리·회복 심볼을 합친 256×256 면 그림.
- `portraits/{Front,Left,Right,Back}.png`: 별도 레이어로 쓰는 투명 캐릭터 초상.
- `Tower_Red_Frame.png`, `Tower_Red_Background.png`: 실제 타워의 빨간 장식·배경 셀을 그대로 추출했다.
- `SelfHeal_Red.svg`, `SelfHeal_Red.png`: 빨간 십자와 회전 화살표로 만든 간단한 자가회복 심볼. 사각 문양을 대신하며 현재 TowerBase의 상단 문양 위치에 맞췄다.

## 제작 방식과 프롬프트

캐릭터 네 장은 **내장 image_gen 도구**로 각각 제작했다. 현재 게임의 `Tower_Sword_Front_Atlas_v2.png`를 화풍·상반신 비율 참고로 사용하고, 기존 `Enemy_Cube_FallenValkyrie_Faces_v4.png`에서 은백색 머리·자주색 눈·날개 투구의 정체성을 가져왔다. 보석과 깃털에는 자가치유형의 붉은 포인트를 넣었다. 측면과 뒷면은 완성된 정면을 추가 참고로 사용했다.

`prompts.json`에 최종 프롬프트 세트가 있고 `generation-manifest.json`과 `generation/`에는 실제 프롬프트·참고 이미지·생성 원본 경로와 패킹 좌표가 있다. 원본 네 장은 `source/`에 보존했다. `Build-Preview.cjs`는 투명 여백 정리와 크기 배치, 기존 타워 레이어의 합성만 담당한다. 회복 아이콘은 간단한 벡터 도형이다.

4개 캐릭터 원본과 최종 4면을 눈으로 검토했다. 후면은 얼굴 없이 머리카락과 투구 뒤쪽을 표시한다. 각 그림의 크기와 배경·테두리·심볼 위치를 같은 캔버스에 맞췄다.

오른쪽을 바라보는 그림은 추가 요청에 따라 내장 image_gen으로 이빨을 제거하고 닫힌 미소로 수정했다. 최종 초상·면 그림·4면 시트·미리보기에 반영했다. `generation/Right-no-fang-edit.json`에 수정 프롬프트를 기록했고 이전 원본은 `source/Right-before-fang-removal.png`에 보존했다. 정면·왼쪽·후면의 최종 PNG는 수정 전후 SHA256이 동일하다.

현재 결과물은 이미지 제작과 브라우저 시안이다. Unity의 3D 큐브 프리팹 생성·머티리얼·굴림 로직 교체는 수행하지 않았다. 게임의 기존 몬스터 에셋과 프리팹은 변경하지 않았다.
