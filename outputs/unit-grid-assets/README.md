# 셀 크기 1 기준 에셋 정리

- 타워 캐릭터 아틀라스 14개와 시너지 아틀라스 1개: 조각 크기 512×512, PPU 384 → 512.
- 적 캐릭터 이미지 27개: 512×512, PPU 384 → 512.
- 보드 테두리 아틀라스: 조각 크기 192×192, PPU 128 → 192.
- 공용 배경·장식(512 PPU), 화살표(256 PPU), Stage1 그리드(1×1)는 이미 맞아 있어 유지.
- 타일 팔레트 `Tiles.prefab`의 셀 크기: 1.3333334 → 1.
- `TowerBase.prefab`의 일반·시너지 캔버스 폭: 1.3333334 → 1. 문양 위치와 크기는 같은 비율로 조정.
- 적 프리팹 3개의 큐브 폭과 애니메이션 기준 변 길이: 1.3333334 → 1. 큐브 중심 Z: -0.6666667 → -0.5.
- `TowerVisual`, `EnemyCubeMeshVisual`의 새 컴포넌트 기본 크기도 1로 통일.

PPU는 전체 아틀라스 해상도가 아니라 **한 스프라이트 조각의 픽셀 수 / 원하는 월드 크기**로 결정한다. 예를 들어 1024×1024 아틀라스 안에 512×512 조각 4개가 있으면 PPU 512로 각 조각이 월드 1×1이 된다. PPU 변경 자체로 원본 화질이 높아지지는 않는다.

이미지 재샘플링은 하지 않았다. PNG 43개의 SHA-256이 작업 전과 동일하다. 수정한 메타 43개는 PPU 한 줄만 달라졌으며 GUID, 스프라이트 ID, 슬라이스, 피벗, 보더는 그대로다. UI 전용 아이콘, 장비 마스크, 효과 에셋과 현재 작성 중인 `Scripts/New` 코드는 변경하지 않았다.

검증: 아틀라스 조각 160개 및 단독 적 스프라이트 27개의 기본 월드 폭이 1임을 확인. 오프라인 런타임 C# 컴파일 경고 0, 오류 0. Unity 실행 및 화면 검증은 하지 않았다.

`before/`에는 수정한 파일 50개의 원본, `changes.json`에는 수정 목록, `verification.json`에는 검증 결과가 있다. `Normalize.ps1`은 최초 상태용이며 중복 실행을 막도록 작성되어 있다.
