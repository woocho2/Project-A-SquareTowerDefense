# 3D 큐브 Enemy 연결

후속 변경: 큐브 크기 및 타일 정원은 [3×3·9마리 배치](../enemy-nine-slots/README.md)에서 축소·제한했습니다. 아래 크기와 미리보기는 최초 연결 당시의 기록입니다.

`Assets/2. Prefab/3. Enemy/Enemy.prefab`에 실제 6면 메시와 6개 재질을 연결했습니다. 원래 프리팹 GUID를 유지합니다.

- 정면: 자가치유(빨강), 후면: 방어(노랑), 왼쪽: 행동력(초록), 오른쪽: 이동력(하늘), 위: 자물쇠(회색), 아래: 모래시계(보라).
- 원본 512px 불투명 `StateFaces_v1/Textures3D` 텍스처를 사용합니다. 옆면도 개별 UV와 재질을 가지며, 큐브 변 길이는 패스 타일에 맞춘 1.333333입니다.
- 루트에 기존 `EnemyMoveController`, `EnemyHealthController`, `EnemyDebuffController`, `EnemyUIController`, 2D 트리거 충돌체와 Kinematic Rigidbody2D를 연결했습니다. HPBar는 기존 프리팹을 중첩합니다.
- `CubeVisual3D`만 90도씩 회전하고 모서리를 넘을 때 카메라 쪽으로 솟아오릅니다. 루트의 경로 좌표와 HP바는 회전하지 않습니다. 코너, 역방향 이동, 풀 재사용을 지원합니다.
- 일반·이동형·방어형 풀은 공통 새 큐브를 소환합니다. 삭제된 이동형·방어형 데이터의 기존 수치는 새 `Data/Enemy_Wave*_Stats.asset`에 보존했습니다. 보스 풀은 기존 보스 프리팹을 사용하며, 베이스 풀의 누락된 데이터·Health 참조도 스테이지와 일치시켰습니다.

현재 연결 범위는 외형·이동과 기존 전투 동작입니다. 표시된 면에 따른 자가치유·방어·이동력·행동력 보너스, 자물쇠 약화, 모래시계 무적은 아직 전투 판정에 적용하지 않습니다.

검증: Unity 6000.3.9f1 별도 검증 프로젝트의 실제 PlayMode에서 24개 자세/96개 회전 전이, 6면과 회전 중간 자세 GPU 렌더링, 실제 풀 소환·코너·역주행·2D 타격 대상 검색·피격·HP바·디버프·회수·재사용·굴림 중단 복구·기존 스프라이트 큐브 호환을 통과했습니다. 현재 전체 게임 C# 소스 컴파일과 설치 후 GUID/fileID 및 Stage1 풀 연결 검사도 통과했습니다. 전체 Stage1 장시간 플레이 검증은 수행하지 않았습니다. 별도 검증 프로젝트의 UI DLL 스크립트 참조 보정은 실제 프로젝트에 설치하지 않았습니다.

`overview.png`와 `renders/`는 Unity 카메라로 직접 렌더링한 결과입니다. `before/`는 연결 전 프리팹·풀·스테이지 백업입니다. `EnemyCubeBuild.cs`, `EnemyCubeRuntimeCheck.cs`는 검증용 코드이며 실제 Assets에 추가하지 않습니다.
