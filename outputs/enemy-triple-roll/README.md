# 또각·또각·톡: 타일당 세 번 굴림

새 3D 큐브 적에 한 타일당 세 번의 90도 굴림(총 270도)을 연결했습니다. 프레임마다 큐브 자세와 이동 좌표를 함께 계산하므로, 그림은 큐브 표면에 붙어 회전합니다. 기존 스프라이트 적은 종전 이동 방식을 유지합니다.

- 기본 속도 1에서 단일 타일 이동: 약 0.4초. 출발 준비 0.04초 + 세 번의 굴림 0.29초 + 마지막 착지 0.07초입니다.
- 출발할 때 살짝 눌리며 뒤로 8도 기울었다가 나갑니다. 각 굴림은 모서리를 넘는 중간 구간에서 빨라지고, 착지에서 잠깐 가볍게 눌립니다.
- 여러 칸 이동은 첫 칸에서만 준비하고 중간 칸에서는 이어서 구릅니다. 마지막 실제 도착 지점에서만 강한 착지 눌림을 적용합니다. 목적지가 막혀 중간에 멈춘 경우에도 마지막 도착한 칸에서 마무리합니다.
- 바닥 그림자는 적 루트의 별도 메시입니다. 큐브가 떠오를 때 작고 옅어지고, 착지 때 넓어집니다. 큐브가 회전해도 그림자는 바닥에 남습니다. 같은 재질과 사각 메시를 공유하며 추가 이미지 텍스처가 필요하지 않습니다.
- 마지막 도착 뒤 그림이 누웠다면 기존의 90도 제자리 점프로 정방향을 찾습니다. 이 점프는 0.4초 이동 시간에 별도로 더해집니다. 점프에도 같은 그림자 반응을 적용했습니다.
- 실제 면 상태도 매 90도 착지에 맞춰 갱신합니다. 타일 점유는 세 번의 굴림을 모두 마친 뒤 한 번만 도착 타일로 바꿉니다. 9자리 정원과 도착 예약은 유지합니다.
- 피격·풀 회수·중단 시 크기, 위치, 그림자를 복구합니다. 재소환 시 면 에셋과 시작 면을 다시 뽑고 정방향으로 시작합니다.

조절 위치: `EnemyCubeMeshVisual`의 **세 번 굴러 한 타일 이동 → Tile Roll Duration**. `EnemyMoveController.Move Speed`는 새 메시 큐브에서 속도 배율(1=기본값)로 사용합니다. 게임 전체 시간 배율도 그대로 적용됩니다.

검증: 전체 게임 C# 컴파일 성공. Unity 6000.3.9f1 별도 PlayMode에서 24가지 자세 × 4방향 × 121시점, 총 11,616개 샘플의 이동 단조성·최종 270도 자세·예비 동작·그림자 반응을 통과했습니다. 실제 기본 속도 한 칸 이동 약 0.40초, 코너와 역방향 세 번 굴림, 480회 랜덤 재소환, 도착 후 점프의 24가지 자세, 점프 중 피격 사망/재사용, 9마리 동시 이동과 예약/정원 회귀 검사도 통과했습니다. 전체 Stage1 장시간 플레이는 별도로 수행하지 않았습니다.

`triple-roll.gif`와 `overview.png`는 실제 Unity GPU로 렌더링했습니다. GIF는 두 타일 사이의 세 번 굴림과 착지를 보여줍니다. 애니메이션용 새 음향은 추가하지 않았습니다. 검증 스크립트는 실제 게임 Assets에 설치하지 않습니다.
