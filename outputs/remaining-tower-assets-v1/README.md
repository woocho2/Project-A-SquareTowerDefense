# 남은 큐브 타워 48종

후속 작업에서 게임에 연결했습니다. 현재 번호·소환 데이터·검증 범위는 `../all-tower-assets-connection-v1/README.md`를 참고하세요.

기준: `Assets/27. 기획 통합.txt`의 2026-10-13 확정된 **타워의 컨셉 — 56종의 이름**. 기존 검 4종·도끼 4종을 제외한 활, 창, 방패, 해머, 불, 물, 대지, 바람, 얼음, 전기, 빛, 어둠의 네 역할, 총 48종을 제작했습니다.

제작 방식은 내장 `image_gen`입니다. [정확한 전체 프롬프트](prompts.json)와 [생성 기록](generation-manifest.json)을 보관합니다. 기존 검·도끼 정면 캐릭터를 스타일 참조로 사용했습니다. 두꺼운 외곽선, 단순한 눈, 넓고 둥근 사각 얼굴, 큐브 정면용 머리 초상, 역할별 색과 장식을 사용합니다.

스타일 참조 원본은 `outputs/tower-character-layers-v1/before/Sword.png`와 `outputs/tower-character-layers-v1/before/Axe.png`입니다. `generation-manifest.json`에는 선택된 최종 그림의 프롬프트와 교정 프롬프트를 함께 기록합니다. 교정 전 랜서·서전트·키린 원본은 `history/`에 보관합니다. 키린은 인간 피부의 얼굴을 사슴형 주둥이·용 비늘이 있는 영수 얼굴로 교정했습니다.

## 파일

- `source/`: 생성된 고해상도 원본 투명 PNG 48개. 원본의 알파를 보존합니다.
- `png/`: 256×256 개별 스프라이트 48개.
- `atlases/`: 512×512 문양별 아틀라스 12개. 각 셀 256×256.
- `preview-all.png`: 48종 전체 비교. 기존 브론즈 테두리를 배경으로 사용한 확인용 합성입니다.
- `preview-weapons.png`, `preview-elements.png`, `preview-derived-elements.png`: 16종씩 나눈 확대 비교.
- `asset-manifest.json`: 한국어 이름, 확정 기획 문양 번호, 역할 번호, 스프라이트 이름의 대응표.
- `Build-Assets.ps1`: 원본에서 개별 PNG, 아틀라스, 비교 이미지를 재생성하는 포장 스크립트.

Unity 에셋 저장 위치: `Assets/4. Asset/2. Tower/CubeConcepts/Remaining_v1/`. Import metadata는 PPU 192, 중앙 피벗, Full Rect, 알파 활성화, 무압축, mipmap 비활성화입니다. 아틀라스의 셀 순서는 기존 검·도끼와 동일합니다.

| 위치 | 역할 |
| --- | --- |

| 우상 | 블루 · 단일 |

| 우하 | 블랙 · 디버프 |

티어는 기존 공용 테두리를 재사용합니다. 새 그림은 **완성 초상 한 레이어**이며 기존 검·도끼처럼 얼굴/머리장식으로 분리한 레이어가 아닙니다. 게임 코드·프리팹 연결 및 기존 에셋 교체는 이 제작에 포함하지 않았습니다. 기획의 물 추가 및 원소 번호 변경은 런타임과 차이가 있으므로 매핑은 최신 기획 번호를 명시적으로 기록합니다.

기획상의 구분: 헌터의 모자·석궁, 랜서의 깃발 창·말 장식, 서전트의 방패 분대, 실드메이든의 둥근 방패, 메이슨의 망치·정, 인간 블랙스미스의 모루·화덕, 탐욕스러운 드워프의 금화, 액체 운디네와 사람 모습 나이아드, 새/영수/늑대 번개 마수, 흰색·금색 루시퍼의 금 간 광륜과 여러 쌍의 날개를 작은 초상 안에서 구별합니다.
