# 일반 타워 기준 몬스터·보스 캐릭터 크기 통일 — 2026-10-17

현재 프로젝트의 몬스터·보스 전체 6종에 적용했습니다: 아스가르드 발키리·브륀힐드·로키, 알프헤임 일반 엘프·부족장·족장. 기존 일반 타워 아틀라스는 기준 자료로 사용하며 변경하지 않았습니다. 그림의 색·디자인은 유지하고 제작 패킹 좌표를 수치로 보정했습니다. 새 이미지 생성은 사용하지 않았습니다.

## 공통 기준

일반 검 타워의 256×256 스프라이트 셀에서 양 눈 간격이 약 39~40px인 것을 기준으로 설정했습니다. 같은 셀 기준으로 얼굴 중심 X128, 눈높이 Y160, 눈 간격 39.5px, 턱선 Y184, 몸 아래선 Y244입니다. 몬스터의 512×512 텍스처에는 두 배 좌표를 적용합니다.

전체 알파 외곽을 맞추면 관·귀·넓은 머리카락 때문에 얼굴이 작아집니다. 눈 위치·눈 간격으로 머리를 배치하고, 눈~턱 구간과 턱 아래 몸 구간을 각각 공통 기준에 맞춥니다. 관·뿔·머리 윗부분은 머리 기준 배율을 따릅니다. 부속 장식의 모양에 따른 외곽 차이는 유지합니다.

동일 역좌표 변환을 장비 마스크에도 적용합니다. 초상은 알파를 고려해 보간하고, 데이터 마스크는 최근접 표본으로 흑백을 유지합니다. 피부·머리카락 보호는 기존 마스크를 그대로 따릅니다. 배경·공용 장식·상태 배지·콜라이더·이동·프리팹 배율·스탯·게임 규칙은 바꾸지 않았습니다.

## 적용과 재현

- `layout-config.json`: 전체 공통 기준과 캐릭터별 원본 랜드마크. 새 캐릭터도 이 기준을 사용합니다.
- `before/`: 적용 직전 원본 초상·마스크·메타·외형 설정. 재실행의 고정 원본으로 사용하여 누적 축소를 막습니다.
- `Apply-Layout.cjs`: 6종의 실제 Assets 텍스처와 마스크를 보정. 메타/GUID·스프라이트/텍스처 ID·외형 참조를 유지합니다. 새 원화를 감지하면 이전 스냅샷으로 덮어쓰지 않고 재보정이 필요하다는 오류를 냅니다.
- `Inspect.cjs` → `Measure.cjs --after` → `Verify.cjs`: 실물 텍스처의 홍채를 별도로 측정하여 눈 위치·크기를 확인합니다. 배경 혼동을 피하기 위해 색/얼굴 영역을 제한합니다. 채색·하이라이트 때문에 약 2px 측정 오차를 허용합니다.
- `Preview.cjs`: 비교 그림 갱신. 일반 타워와 동일한 논리 캔버스 배율로 표시합니다.
- 알프헤임 제작은 `../alfheim-monsters-v1/Rebuild-Final.cjs`에서 보정까지 함께 실행합니다.

## 확인 결과

`verification.json`에 6종의 실제 홍채 중심과 간격을 기록했습니다. 눈높이·중심 오차 1px 미만, 눈 간격 오차 최대 약 1.5px(256 셀 기준), 몸 아래선 전부 488px(512 텍스처)입니다. 마스크 흑백·투명 영역 침범·텍스처 512 규격·캔버스 가장자리 잘림 없음·기존 메타 및 외형 설정 바이트 보존을 확인했습니다. 런타임 코드는 수정하지 않았고 Unity 임포트·플레이 검증은 별도로 수행하지 않았습니다.
