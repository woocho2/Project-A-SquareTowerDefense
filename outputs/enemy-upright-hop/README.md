# 도착 후 통통 뛰며 정방향 찾기

후속 변경: [타일당 세 번 굴림과 그림자](../enemy-triple-roll/README.md)를 연결했습니다. 아래의 제자리 점프는 새 이동의 마지막 착지 뒤에도 이어집니다.

새 3D 큐브 적이 한 번의 이동을 모두 마친 뒤, 보이는 그림이 옆으로 눕거나 뒤집혀 있으면 제자리에서 90도씩 점프 회전합니다. 옆으로 누운 경우 한 번, 거꾸로인 경우 두 번 뛰며 가장 짧은 방향으로 정방향을 찾습니다. 처음부터 정방향이면 추가 동작을 하지 않습니다.

- 출발 전 짧은 웅크림 → 0.18초 점프와 큐브 전체 90도 회전 → 0.07초 착지 눌림·복원 순서입니다. 한 번에 약 0.29초, 두 번에 약 0.58초가 걸립니다.
- 그림만 역회전하지 않습니다. 큐브 전체가 돌아가며, 정사영 화면에서도 점프가 보이도록 깊이 상승에 작은 화면 위쪽 이동을 더합니다.
- 보이는 물리 면과 에셋 배정은 유지됩니다. 회전 완료 때 논리 자세도 갱신하므로 이후 굴림이 새 자세에서 이어집니다.
- 여러 칸 이동 중에는 자세를 고치지 않고 마지막 도착 지점에서만 동작합니다. 역방향 이동에도 적용합니다. 목적지가 막혀 한 칸도 이동하지 않았다면 점프하지 않습니다.
- 타일 점유·자리 예약·2D 충돌체·HP바는 그대로 유지하고 `CubeVisual3D`만 움직입니다. 점프가 끝날 때까지 이동 완료 대기를 유지합니다.
- 점프 중 피격·사망·풀 반환 시 코루틴을 취소하고, 마지막 확정 자세와 원래 크기·위치를 복구합니다. 재소환은 기존처럼 에셋과 시작 면을 다시 뽑고 정방향으로 시작합니다.
- 세 번 굴러 타일을 이동하는 앞선 제안이나 추가 음향·먼지 효과는 이번 변경에 포함하지 않습니다.

조절 위치: `EnemyCubeMeshVisual`의 **도착 후 정방향 점프** 아래 `Upright Hop Duration`, `Upright Hop Height`, `Upright Impact Duration`.

검증: 전체 C# 컴파일과 Unity 6000.3.9f1 별도 PlayMode에서 24개 도착 자세의 0/1/2회 점프, 매 착지 90도 확정, 실제 상승·눌림, 같은 면·에셋 유지, 루트·HP바 고정, 위치·크기 복원, 점프 중 피격 사망과 풀 재사용을 검사했습니다. 기존 랜덤 소환·코너·역주행·9자리 정원·동시 이동 회귀 검사도 포함합니다. 실제 Stage1 장시간 플레이는 별도로 수행하지 않았습니다.

`upright-hop.gif`는 Unity GPU로 직접 렌더링한 48프레임 미리보기입니다. `overview.png`는 대표 자세입니다. 검증 코드는 실제 게임 Assets에 설치하지 않습니다.
