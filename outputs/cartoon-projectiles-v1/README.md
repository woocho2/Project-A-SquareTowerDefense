# 카툰 투사체 v1

내장 image_gen으로 만든 투명 PNG 시안 26종입니다. 스플래시 13종과 총알 13종이며, png 폴더에 선택한 파일을 모았습니다.

- 스플래시 무기군: 은회색 오브 내부의 검·도끼·활·창·방패·망치.
- 스플래시 원소군: 불(주황), 얼음(하늘색), 번개(노랑), 바람(민트), 대지(갈색), 빛(백금), 어둠(검은 중심과 보라색 고리).
- 총알 무기군: 매화 꽃잎 검기, 투척 손도끼, 화살, 긴 자루의 투척 창, 원형 방패, 투척 망치.
- 총알 원소군: 각 원소의 색상과 성질을 표현한 에너지 탄. 어둠은 블랙홀 컨셉 유지.

preview.html을 열면 스플래시와 총알을 나란히 비교할 수 있습니다. 배경, 표시 크기와 비행 미리보기를 바꿀 수 있고, 이미지 클릭으로 원본 PNG를 볼 수 있습니다. 아래 작은 샘플은 32px 표시입니다.

manifest.json에는 문양 번호와 대응하는 투사체 ID, 선택한 파일 경로가 있습니다. prompts.json은 최초 생성 프롬프트 26개, spear-refinement-prompt.txt는 창의 자루를 늘린 최종 수정 프롬프트입니다. source 폴더에는 생성 원본과 창의 이전 시안도 보관했습니다.

PNG 26종은 Assets/4. Asset/3. Projectile/Cartoon의 Bullet·Splash 폴더에 들어 있습니다. 총알 13종은 Resources/Projectiles/201~213 프리팹에 연결되어 모든 티어에서 사용합니다. 전용 이미지는 원래 색을 유지하며, 위성 대기와 풀 재사용 때도 타워 문양으로 바뀌지 않습니다. 잔상·파티클 색은 각 프리팹의 Prefab Effect Color로 지정합니다. 표시 크기는 프리팹 기본 배율 1과 GlobalProjectileManager의 전역 배율(기본 0.5)을 적용합니다. 스플래시 13종은 아직 게임 프리팹에 연결하지 않았습니다.
