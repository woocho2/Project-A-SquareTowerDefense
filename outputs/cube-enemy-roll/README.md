# 큐브 적의 경로 굴림

EnemyMoveController는 각 적의 정수 큐브 자세를 보관하고, 전진·후진의 패스 인덱스 한 칸마다 해당 월드 방향으로 90도 굴립니다. 같은 타일 안에서 진형을 조정할 때에는 굴리지 않습니다. 실제 이동 목적지의 진형 오프셋 대신 패스 타일 중심 사이의 방향을 사용합니다.

| 이동 | 보이는 면 | 그림의 윗변 방향 |
|---|---|---|
| 초기 | 정면 | 위 |
| 오른쪽 1칸 | 왼쪽 옆모습 | 위 |
| 이어서 위쪽 1칸 | 아랫면 | 왼쪽 |
| 이어서 위쪽 1칸 | 오른쪽 옆모습 | 아래 |
| 이어서 위쪽 1칸 | 정수리 | 왼쪽 |

위·아래 그림은 사용자 예시의 방향 기준으로 배치합니다. 오른쪽 옆면 이미지가 있으면 해당 그림을 사용합니다. 없을 때만 왼쪽 옆모습을 반전합니다. 이미지의 면뿐 아니라 0/90/180/270도 회전을 함께 저장하므로 경로가 여러 번 꺾여도 자세가 유지됩니다.

EnemyCubeVisual은 이전 면과 들어오는 면을 별도 SpriteRenderer로 동시에 표시합니다. 모서리를 축으로 회전하는 정육면체의 정사영에 따라 두 면의 폭은 cosθ와 sinθ이고, 두 면의 공유 모서리가 맞닿습니다. 중간(45도)에는 두 면이 같은 폭으로 보입니다.

캐릭터 그림만 표시합니다. 상자 바탕·테두리·색상 채움은 사용하지 않습니다. 원본 PNG의 투명 여백을 제외한 영역으로 런타임 스프라이트를 만들고, 각 얼굴·머리 영역을 같은 정사각형 면에 맞춰 배치합니다. PNG 픽셀은 수정하지 않습니다. 잘라 쓰는 픽셀 영역은 각 면의 Rect 필드에 지정되어 있어 그림을 바꿀 때 조절할 수 있습니다. 런타임 스프라이트는 공유 캐시를 사용하므로 풀 재사용 때 새로 만들지 않습니다.

이동 위치와 두 면의 폭·위치는 진행률에 따라 매 프레임 연속 갱신합니다. 프레임을 여섯 단계로 나누던 스톱모션은 제거했습니다. 실제 한 칸 이동 시간은 거리 / EnemyMoveController의 Move Speed로 계산합니다. 값을 낮추면 이동과 굴림이 함께 느려집니다. 별도의 Roll Duration 상한은 제거하여 Move Speed가 실제 시간에 반영됩니다. 기존 프리팹 값은 유지했습니다(일반 1, 나머지 3). 패스 간격 1.5 기준으로 일반은 약 1.5초, 나머지는 약 0.5초이며 진형 오프셋에 따라 달라집니다. 도착 타일 등록 후 0.06초 착지 대기를 유지하고 END에는 대기하지 않습니다. CubeVisual에서는 면 크기(0.86), 착지 대기(0.06), 명암(0.1)을 조절합니다.

충돌체·HP 바는 그림의 회전이나 면 변형을 따르지 않습니다. 이동 중단 시 마지막 완료 자세로 그림을 복구하며, 풀에서 재소환할 때 정면으로 초기화합니다.

일반 적 세 프리팹에 정사각형 발키리 v4 아틀라스 여섯 면을 연결했습니다. 기존 중간 보스와 최종 보스는 각각 타락한 브륀힐드와 타락한 로키 여섯 면으로 연결했습니다. 전체 SpriteRenderer 틴트는 흰색으로 복구하고, `EnemyEquipmentPalette.shader`와 종류별 머티리얼로 검은 장비 및 보석만 부분 색상 처리합니다. 자가치유형은 붉은색, 이동력형은 하늘색, 행동력형은 초록색, 방어형은 노란색, 전체회복형은 흰색입니다. 보스는 별도 캐릭터 그림의 원래 장비 색상을 사용합니다. 얼굴·눈·머리카락·금색 장식 및 보라색 날개 색상은 유지합니다. 검은 날개 장비 부분은 투구와 함께 바뀝니다. 현재 그림은 얼굴과 투구만 있으므로 새 몸통 갑옷을 추가하지 않습니다.

머티리얼은 `Assets/4. Asset/4. Enemy/Asgard/CubeValkyrie/EquipmentPalettes/`에 있습니다. `Dark Equipment`와 `Jewels` 색상을 조절하면 됩니다. 굴리는 이전 면과 들어오는 면이 같은 머티리얼을 공유하고, 각각의 면 인덱스와 원본 Sprite rect를 MaterialPropertyBlock으로 전달합니다. 좌우 반전·회전·여백 제거 시에도 원래 그림 좌표로 마스크를 판정합니다. v4 아틀라스를 사용하며 이전 v1~v3 이미지는 사용자 요청으로 삭제했습니다. 마스크는 발키리 여섯 면의 장비 위치에 맞춘 것으로, 새 캐릭터에는 위치 기준을 별도로 조정해야 합니다.

행동력형과 전체회복형은 아직 EnemyType·능력·웨이브·풀에 없으므로 `Assets/2. Prefab/3. Enemy/VisualVariants/Enemy_Action_Visual.prefab`과 `Enemy_GroupHeal_Visual.prefab`을 일반 프리팹의 외형 변형으로 준비했습니다. 이 두 프리팹의 현재 게임 동작은 Normal을 상속하며 새 특성은 구현하지 않았습니다. 기존 보스 프리팹을 일반 적의 새 유형으로 바꾸지는 않았습니다.

`OrientationCheck.cs`는 실제 `EnemyCubeOrientation.cs` 및 `EnemyCubeRollGeometry.cs`와 함께 .NET 콘솔로 실행합니다. 요청 경로, 24가지 자세, 96개 방향 전이의 역연산, 모든 자세에서 같은 방향 4회 굴림의 복구를 검증합니다. 굴림 기하도 1001개 시점에서 모서리 연결·정규화된 회전축·단조로운 이동·실루엣 유지를 검증합니다. Unity Test Runner용 회귀 테스트는 `Assets/Editor/Tests/EnemyCubeOrientationTests.cs`와 `EnemyCubeRollGeometryTests.cs`에 있습니다.

`preview.html`은 C# 검증기가 생성한 `trace.js`의 자세와 `geometry.js`의 굴림 샘플을 사용해 요청한 경로를 시각화합니다. 순간 보기 슬라이더로 두 면이 연결되는 모습을 확인할 수 있습니다. 게임의 실시간 화면을 캡처한 자료는 아닙니다.

미리보기 상단에서 다섯 색상을 선택할 수 있습니다. `equipment-preview.js`는 셰이더와 같은 부위 판정식을 사용하고, 원본을 그대로 담은 `face-sources.js`로 로컬 파일에서도 Canvas 픽셀 접근 오류 없이 표시합니다. 30개 면/색상 조합에서 얼굴·눈 영역, 금색 및 알파 보존 검사를 수행합니다. 최신 둥근 모서리 비교는 `../synergy-cube-characters-v1/browser-preview.png`와 `../synergy-cube-characters-v1/unity-preview.png`에 있습니다. 이전 버전 비교 이미지는 삭제했습니다. 본 게임의 Play Mode 실행은 수행하지 않았습니다.

`equipment-palettes.json`은 색상/프리팹 목록, `equipment-manifest.json`은 최종 경로 및 GUID, `Apply-EquipmentPalettes.ps1`은 머티리얼과 프리팹 적용 스크립트입니다. 검사 결과는 `equipment-validation.txt`와 `../synergy-cube-characters-v1/unity-validation.log`에 있습니다.

미리보기의 이동 속도 슬라이더도 거리 / 속도 방식으로 시간을 계산합니다. 0.25~5 범위로 비교할 수 있고 기본값 1은 일반 프리팹 값과 같습니다. 기하 샘플 사이도 보간하여 미리보기에서 구간별 정지 현상이 생기지 않게 했습니다.

최신 정사각형 캐릭터와 8px 모서리 렌더링은 ../synergy-cube-characters-v1/README.md를 참고하세요. 새 일반 적·보스 모든 면에 같은 모서리 마스크를 적용하며 PNG 원본은 그대로입니다. 기존 프리팹 착지 대기는 0.06초이고 코드의 신규 컴포넌트 기본값은 사용자 조정으로 0.1초입니다. 최신 실제 Unity 비교는 ../synergy-cube-characters-v1/unity-preview.png에 있습니다.
