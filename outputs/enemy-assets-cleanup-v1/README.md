# 사용하지 않는 적 에셋 정리

2026-10-16. 현재 3D 큐브로 사용하는 발키리·타락한 브륀힐드·타락한 로키의 실제 참조를 기준으로 정리했다.

- 유지: `Asgard/CorruptedBosses_v1/`의 보스 아틀라스 2장과 재질 12개, `StateCube3D_v1/`의 공용 메시·그림자·발키리 재질, `StateFaces_v1/Textures3D/`의 발키리 6면 텍스처. 적 그림 폴더에는 총 28개 에셋이 남았다.
- 삭제: 옛 뱀 몬스터, 2D 발키리와 보스 그림, 걷기 애니메이션, 구형 장비 팔레트·문양, 미사용 중간 레이어와 중복 PNG, 기존 2D 일반 적·시각 변형 프리팹 및 헬·수르트·이미르 보스 프리팹. 에셋 72개(그림·재질·애니메이션 66개와 프리팹 6개), 메타를 포함해 152개 파일, 원본 약 15.35 MiB를 Assets에서 제거했다.
- 기존 일반 적 프리팹을 참조하던 매니저 프리팹 1개와 복구/백업 씬 7개의 해당 참조만 현재 발키리 큐브의 알맞은 Health/Move 컴포넌트로 교체했다. 실제 플레이 씬과 보스 소환 풀은 직전 연결 상태를 유지한다.
- 전투 코드와 적 능력치 데이터는 유지했다. 현행 3D 기본 중간보스/최종보스 프리팹도 유지했다.

`removed-assets.zip`에 삭제한 파일과 메타의 원본을 상대 경로 그대로 보관했고, 삭제 전에 모든 압축 항목의 SHA256을 검사했다. `removed-files.json`은 경로·크기·해시 목록이다. `references-before/`에는 참조를 바꾸기 직전 파일이 있다.

`verification.txt`에 삭제 GUID가 Assets에 남지 않았음과 현행 적 에셋/프리팹의 의존성 173개가 실제 메타 GUID로 해석됨을 기록했다. 보스 큐브 연결 검사도 다시 통과했다. Unity는 실행하지 않았다.

과거 제작 스크립트가 삭제된 중간 레이어나 옛 프리팹을 입력으로 요구하면, 필요한 원본을 이 압축 파일에서 outputs의 별도 작업 폴더로 추출해 사용한다. 제작 원본을 다시 Assets에 복원할 필요는 없다.
