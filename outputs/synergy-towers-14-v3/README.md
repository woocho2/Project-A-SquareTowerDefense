`source/`는 고해상도 투명 원본 14개, `png/`는 256px 정면 PNG 14개, `Synergy_14_Characters_Atlas_v3.png`는 4×4 아틀라스입니다. 아틀라스는 위 표 순서로 좌상부터 행 우선으로 채우며 마지막 두 칸은 비웁니다. `preview-all.png`에서 14종의 이름과 조합을 함께 볼 수 있습니다.

Unity 에셋은 `Assets/4. Asset/2. Tower/SynergyCube/Concepts_v3/`에 저장합니다. 개별 이미지 14개와 아틀라스 1개에 가져오기 메타데이터를 제공합니다. PPU192, 중앙 피벗, Full Rect, 투명 알파, 무압축, mipmap 비활성화입니다. 이미지는 전체를 축소해서 256px 캔버스의 중앙 224px 영역에 넣으며 원본 그림을 자르거나 새 바탕을 그리지 않습니다.

스카디는 겨울 사냥꾼의 활·얼음에 물 장식을 더했습니다. 발드르는 방패 대신 물·불·빛을 배·물결·불꽃·광채로 표현합니다. 새 뇨르드는 바다·바람·방패를 파도 왕관과 뱃사람 보호 표식으로 표현합니다. 브록·에이트리는 한 칸에 두 형제를 함께 넣습니다. 오딘은 한쪽 눈을 안대로 가리고, 헬은 살아 있는 얼굴과 차가운 영체 얼굴을 반씩 나눕니다.

기존 v2 에셋과 런타임 카탈로그는 유지합니다. 이번 작업은 새 그림과 가져오기 에셋 제작이며 소환 조합·스탯·효과·게임 연결 변경은 포함하지 않습니다. 기획에서 효과는 아직 미정입니다.

정확한 전체 프롬프트는 [prompts.json](prompts.json), 생성 원본 경로는 `records/`, 에셋 경로·GUID·아틀라스 좌표는 `manifest.json`, 확인 결과는 `validation.txt`에 보관합니다. 스타일 참조는 `outputs/remaining-tower-assets-v1/preview-weapons.png`, 구성 참조는 기존 `Synergy_Thor_Front_v2.png`이며 새 이미지의 눈은 일반 타워처럼 단순하게 그렸습니다.
